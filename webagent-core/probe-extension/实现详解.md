# VS Code配套扩展实现详解

## 架构与边界

此目录是独立产品适配层；0.2开始直接复用arena-model-probe/src的五个分析模块（不是另造分类器）。VS Code命令 → 有界回环HTTP客户端 → 现有agent-host本机API；外部已初始化MCP会话单独完成挑战。无需新增宿主权限或执行接口。用户点击桥接菜单仅调用已有webagent.openBridge命令，不改WebAgent源扩展或安装副本。

## client.js

- `localBase`用URL解析，只允许http和回环地址；拒绝凭据、非根路径、query/hash；localhost规范化为127.0.0.1，避免DNS解析到非本机。不是验证进程身份，其他本机进程也能监听端口。
- `parseObservation`先限制UTF-8字节数2048再JSON.parse，要求精确五字段、固定schema/origin、允许的pageKind、64位小写十六进制pageDigest及时间窗口。now可注入测试，生产使用Date.now；主机再次独立校验。
- `request`连接客户端只接受GET diagnostics/某个check和POST创建check，不能访问mcp、文件或执行路由；请求体再次过schema。HTTP响应最大65536字节，10秒总截止，不跟随重定向，AbortSignal用于卸载取消。错误不带响应正文，不尝试第二次请求；这不是对POST的回滚。

## extension.js

- `activate`创建一个输出频道，注册命令并持有pending/busy/disposed及controllers，不访问网络、不读取剪贴板、不恢复磁盘状态。
- `allowed`检查受信任本机窗口；uiKind必须为Desktop且remoteName存在时禁用，避免远程工作区与本机主机含义错位。`base`读取WebAgent共享配置，但交给localBase严格过滤。
- `api`每次请求前重查权限，登记AbortController并在finally清除。
- `show`只在实例可用时更新纯文本输出，不创建Webview，不执行HTML。`identityView`挑选并校验有限长度的主机ID、工作区和版本，丢弃其余字段，例如secretKey。
- `run`用busy序列化命令。diagnostics仅GET；import用遮蔽输入框并校验摘要，开始新请求前丢弃旧记录；copy须单独确认系统剪贴板且每条只能复制一次；refresh绑定创建时地址与hostInstanceId；forget仅丢弃本地内存，不调用主机全局DELETE；bridge只打开已安装WebAgent的Bridge。取消输入不发送；失败不自动重试。输入验证失败不把输入回显进错误提示。analyze分支通过showOpenDialog明确选本地文件，调用readObservation/analyze，不用本机HTTP或模型API。
- `dispose`置disposal标记、丢弃pending并abort所有登记请求，VS Code清理注册命令和输出频道。`deactivate`无另一个全局实例，不另启关闭流程。已经到达主机的POST不能因取消回滚，等待TTL即可。
- pending只保存当前checkId、challenge、expiresAt、origin与主机ID；复制成功后删challenge，确认后也删。服务器TTL决定可用性；过期内存记录在下次copy/refresh或卸载时丢弃，没有后台轮询。不会自动清系统剪贴板，因为不能误删用户后来复制的数据。

## package.json / LICENSE / package_vsix.py

package.json定义独立ID、0.2.0版本、VS Code最低1.90、ui运行位置、拒绝未受信任/虚拟工作区及七个命令。现代VS Code根据contributes.commands自动按需激活，无需通配activationEvents。未声明扩展依赖，避免从Marketplace自动安装未发布依赖。LICENSE使用项目ISC许可。

Python `build`用Path定位目录，读取manifest，在dist生成VSIX。包含package.json、extension.js、client.js、analysis.js、analysisWorker.mjs、README.md、LICENSE及两份VSIX元数据；再白名单复制registry/classify/probe/learned/interceptor原源码到engine，写入ESM package.json和source-hashes.json，不递归打包，拒绝输入文件符号链接。xml escape处理标识、zipfile压缩；只需Conda Python标准库。包没有原型自动启动入口、recon、测试fixture或后台轨迹脚本；interceptor只作为离线解析器导入，不安装网络钩子，不自动安装/执行。VSIX是开发发行包，未宣称Marketplace签名。

## probeCompanion.test.js与验证

`main`按三层验证：localBase/parseObservation输入拒绝；隔离HTTP服务验证成功、重定向不跟随、超限/坏JSON/AbortSignal；VM加载实际extension.js并替换vscode/client传输。`fakeRequest`仅返回合成主机与challenge，`invoke`执行注册命令；registerCommand登记handler且dispose移除。createOutputChannel返回clear/appendLine/show/dispose桩以检查无secret/challenge日志；showInputBox、showWarningMessage、showInformationMessage、showQuickPick与writeText均为无UI/无系统剪贴板替身，executeCommand不执行真实Bridge。

覆盖激活零网络、未信任/远程拒绝、非法摘要不发出、显式复制与取消、查询/丢弃、无自我确认，以及清理订阅。真实HTTP只监听临时回环端口，不访问外部账号。运行`node webagent-core/agent-host/tests/probeCompanion.test.js`或根目录`npm test --prefix webagent-core/agent-host`。

VSIX构建/ZIP检查与这些测试不证明实际VS Code API兼容或安装成功；需按README在用户桌面安装验收。原型SSE/证据混用/全局停止/轮询竞态仍未全修，不由这个安全适配层的测试代替。

失败时清空旧结论，避免旧echo-confirmed被误读为本次成功；主机实例/记录身份不匹配即丢弃pending。补充验证：配置变化后查询仍绑定旧地址；inputGate/releaseInput延迟输入，第二次命令不排队；fakeRequest的holdNetwork延迟请求，dispose中AbortSignal必须生效；注入clock验证过期不再发请求，重启身份不匹配后不能重复用旧记录。

## analysis.js / analysisWorker.mjs / sample-observation.json

validateObservation核对新schema、固定来源origin、requestId、观察时间、截断标记、有限来源的evidence、text、可选UUID映射和指标；不接受用户提供的weight/代码/后台连接参数。输入总量256KiB、text200000字符、evidence100条、map1000条、frame64条；映射的UUID格式独立验证。不同于连接摘要，离线历史观测不要求10分钟内。它不是通用脱敏器。

readObservation只读取用户明确选择的本地文件：open后stat检查普通文件与大小，再用LIMIT+1的固定buffer循环读取，防止stat之后增长导致无界分配；finally关闭句柄。文件I/O没有宣称完整可中断/10秒截止；文件打开后的计算才有Worker预算。远程窗口仍拒绝，URI authority不接受。

analyze验证并复制输入，根据安装包engine目录或源码开发目录选择固定引擎路径；不会让输入指定模块。每次新建Worker并设置64MiB old/16MiB young内存预算、10秒计算截止。finish只结算一次，清timer/abort监听并terminate Worker；abort取消，不自动重跑；error和无结果exit都失败。Worker不是OS安全沙箱，只执行随包受信任源码，不执行输入中的代码。

Worker的load只从确定目录导入五个原模块，不导入main/runmodel/idmap，不调用网络安装/访问入口。SSETap解析用户text产生模型/协议线索；原classify、runCanaries、parseCodename、fingerprintVector和matchTokenizer产出候选、命名提示、向量及分词参考。runCanaries在此只分析文本，不发送题库。

映射按本次输入构造；同一ID对应不同名称时记录conflicts且不替换。无冲突的UUID以idmap.resolve候选送入原分类器，保留原始来源在报告sources中，不让原UUID的较高权重压过已解析名称。候选与协议的confidence显示为heuristicScore，原始text/detail不返回报告；模型字段自身仍可能私密。同来源/模型/家族由bySource保留最高权重一条，避免原解析器与适配层重复计数；参考分不等于统计概率。

输出schema为webagent-model-analysis/v1，保留requestId/observedAt、registry版本、候选/备选、sources、协议、映射冲突、codename、fingerprint、tokenizer、parserLimit/truncated及未核验说明。worker状态每次新建，不共享BUS/map/localStorage；尚未移植历史存储。sample-observation.json是参考格式的合成示例，不是用户真实会话。

## 新增验证

probeAnalysis.test.js的main验证实际原模块解析与候选、相邻与并发请求隔离、映射冲突、截断标志、计算取消/预取消、文件大小/JSON格式；只用合成样本，不访问账号。probeCompanion的showOpenDialog桩返回fixtureDirectory内明确写出的样本，实际执行文件读取和Worker，断言本机HTTP调用计数不增加、输出确有analysis schema和候选。构建包需再解包到临时目录验证无源码仓库时独立工作，源hash需逐文件匹配。真实VSCode、浏览器联动、完整历史和授权自动化仍需独立验收。

package_vsix.py的verify_archive把刚构建且已校验白名单的包解到临时目录，核对五个引擎文件hash，再调用系统Node对固定合成模型观测进行离线分析。build的verify开关默认false；CI用--verify开启，30秒子进程上限、非零退出即失败；没有仓库相对依赖也必须能运行。不激活VSCode、不装浏览器钩子、不访问账号。CLI仅一个验证命令，避免后续成功命令掩盖前面的构建/计算失败。
