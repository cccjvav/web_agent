      工具接入与审批
      
          
      仅本机操作者登记及批准。支持已启动的回环 HTTP(S)，或经本机预览/确认后启动的 stdio MCP；或显式确认的公网HTTPS MCP；不自动安装程序。公网需DNS/实际连接地址检查、不跟随跳转，登记会发送初始化及可选凭据，后续参数须逐次审批。发现工具不等于授权，每次调用分别审批。
      
          
      配置、令牌、审批参数/结果只在本次进程内存保留；请求最多保留15分钟且可能更早淘汰。重启需重新登记/配对；丢失记录绝不是允许重放。外部结果仅为外部自报，不是独立验收。
      
          
          
          
          
          
          
      登记会发送初始化及可选凭据；未知结果先查列表，不重复登记。移除记录不证明外部服务或进程已停止。
      
          
      stdio MCP（启动本机程序）
      
          
      启动本身会执行第三方代码，不是只读发现，也不是OS沙箱。只启动你已安装并信任的程序；不会自动下载、安装或重启。程序仍有当前系统用户的文件和网络权限。
      
          
          
          
      可选env只显式传所需变量；不要把令牌放进args。预览请求发送后会清除输入框中的env值，重新预览需重填。程序hash与reviewFiles不能覆盖所有依赖。Windows系统Node/Python路径可在VS Code的CMD里用where node / where python查找；Python环境按Conda管理。
      
          
          
      
          
          
      预览2分钟有效且只能用一次。启动后，每次工具调用仍需下方独立审批；取消调用会停止整个stdio进程，不保证撤回已发生的效果。
      
          
      
          
      跨文件内容检查点（本机手动恢复）
      
          
      任务前选择1–12个已有UTF-8文件，每行一个工作区路径。原文只存本机内存15分钟，单文件64KiB、合计256KiB，重启丢失。先保存或保留编辑器草稿；不捕获未保存内容。
      
          
          
          
          
      
          
      任务后先预览，再明确确认恢复。非原子事务；失败保留部分结果，不重放。
      
          
      
          
      只恢复选定已有文件的磁盘内容，不撤销删除/重命名/新文件/命令外部效果。全部预检后逐文件写入，中途漂移仍可能部分完成。关闭未保存编辑器或先另行保留草稿，避免之后保存草稿覆盖恢复结果。
      
          
      固定工作流预览
      
          
      最多12步；工具名固定。写入路径和内容必须是供审阅的字面值；其他参数可用 $steps.步骤ID.字段 引用前序结果。失败/未知即停，无重试。预览只校验结构，不读取文件或保证运行成功。
