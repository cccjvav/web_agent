# 工作台HTML与SVG：所有区域、数据属性及真实功能边界

覆盖[index.html](index.html)、[favicon.svg](favicon.svg)。HTML定义节点和初始状态，行为来自[交互绑定](js/交互绑定详解.md)，不把“有按钮”理解成“功能已实现”。

## 1. 文档头与内嵌脚本

DOCTYPE启标准模式；html lang=zh-CN/data-theme=dark，UTF8/viewport/title，favicon与CSS均相对URL。head唯一内嵌script try读取localStorage webagent-theme，仅light/dark写data-theme；异常吞，用默认深色。它在body绘制前运行降低主题闪烁，不启动模型、联网或写盘；后续dom.initTheme负责按钮/Monaco同步。底部script type=module加载app.js及其ES imports。

## 3. 设置弹层所有页面

modal是role=dialog/aria-modal=true、aria-label提供名称且初始aria-hidden=true/hidden；modal-nav各data-page对应page-ID，modal-main滚动，modal-close有可访问名称。打开会保存触发点、将焦点移入弹层；Tab/Shift+Tab约束在可用控件，Escape/关闭会恢复触发点。该实现仍不是各类读屏器、浏览器缩放和输入法的完整无障碍认证。

chat-stream、agent-stream和bridge-log均有tabindex=0与可访问名称，内容溢出时可聚焦后用方向键滚动；Bridge是命名region，不新增自动朗读的live广播。相邻field-label已通过for关联对应ID；没有可见独立标签的搜索、地址、终端、聊天、插件和隧道输入使用aria-label，不能只依赖placeholder。tabs与右栏使用tablist/tab/aria-selected，聊天、Agent、终端及toast使用live region；文件树、搜索结果和动态标签都用原生button。语义属性不改变后端权限。

|---|---|---|
| help | 使用步骤与内置/Bridge边界 | 顶部帮助与walk-start打开，不再无变化地返回欢迎页 |

## 4. Bridge页所有组

br-head展示bridge-sub/pill；client-recipes的cards/detail/pairing-line由status生成，必须按真实客户端连接方式理解。mcp-block含URL/复制与banner，初始hidden；actions切启停/复制prompt/rules/八个open-site。open-site只是本地指引/外链准备，不声明实际登录；prompt-hint说明规则传递，本轮修复“网页”乱码。

授权block区分本机演示与可选GitHub，acct-label/pill/install-id/usage-line由状态填；gh-token密码输入autocomplete off，token/device/clear按钮分别对应API；没有将GitHub身份等同仓库push授权。

连接设置含conn-label/pill和三个name=tunnel radio：cloudflare默认，named的domain/token，ngrok的domain/token。Quick卡on只是初始class，radio选中与on样式不必总同步；vendor限制文字不是服务端强制规则/实时官方查询。

快速打开details含ql-list/name/url/add；高级details含reset-secret按钮及独立secret-result状态区（role=status、aria-live=polite），展示未发送/结果未知/写入确认但读取失败。文字提“随启动/timeout”不代表页面已有这些设置控件。所有secret/password输入仍是DOM内明文值，不可据type=password声称加密存储。

## 5. 页尾菜单与图标文件

file-menu data-act：new/open/save/preview/undo-save/welcome/custom；manage-menu固定三个入口；agent-pick-menu data-mode ask/plan/code+定制入口。class dropdown/hidden配合bind切换，不是浏览器原生应用菜单。toast用原生hidden属性初始隐藏，dom.toast临时展示；不能与.hidden类混为同一个字段。

favicon.svg的viewBox32×32，rect同尺寸rx8紫色背景；一个path含左右尖括号和斜线三段，白色2.2描边、圆端/圆角、fill none；无JS、网络资源或事件。它不同于扩展24px线框icon，不能用改其中一个期待另一处同步。

## 6. 验证与逐断言说明

[workbenchHtml.test.js](../agent-host/tests/workbenchHtml.test.js)是静态文件测试：required数组遍历检查关键ID；后续检查隧道输入/命令说明、演示授权、相对资源URL、主题/健康/统计/WS节点、two-paths及语义chips。另禁止U+FFFD和已删除占位控件回归。无障碍守卫要求四张欢迎卡均为button、tabs/modal/toast角色存在；遍历每个非隐藏input/textarea/select，要求显式for、包裹label或ARIA/title之一；读取CSS检查input/textarea focus-visible及700px规则内sidebar绝对定位，并读取tabs源码检查动态tab/tree按钮；同时要求三个消息/日志滚动区可Tab聚焦且有名称。

该测试顶层读取HTML/CSS/bind/chat/tabs，for-of断言，失败抛错；**没有浏览器、点击、实际CSS布局或网络请求**。模态焦点及390px边界由独立Chromium测试覆盖，静态“has bind nodes”日志仍不能证明所有辅助技术行为。

```bat
npm test --prefix webagent-core/agent-host -- --filter=workbenchHtml
npm test --prefix webagent-core/agent-host -- --filter=workbenchRuntime
```

本文件非JS段与内嵌脚本人工解释，登记不冒充AST完整性证明。真实浏览器焦点、输入法、DPI及模型/手机测试继续保留实际验收状态。

## 主机核对页
Bridge侧栏增加bridge-host及btn-host-diagnostics。page-diagnostics包含diagnostic-identity、expected-host、host-comparison、diagnostic-capabilities和刷新/核对按钮；只收主机UUID，不要求粘贴MCP凭据。

### operations页stdio入口
ops-stdio-config输入程序/args/cwd/env/reviewFiles JSON，btn-stdio-preview只读审阅，ops-stdio-review安全纯文本显示，btn-stdio-start需浏览器确认且一次性。与已有HTTP登记、工具逐次审批分离，env不写localStorage；面板明确说明启动本身有副作用/不是OS沙箱。

Bridge正文新增execution-controls：主机模式回读、两模式按钮、Read/Edit/Execute/Capture复选框、保存/重新读取及role=status反馈。fieldset只表达远端权限，绑定在bridge.js；切页签不会更改执行模式。验证见executionControl与浏览器控件回归，Capture不代表新增截图工具。

文件菜单新增“预览当前文件修改”；diff-pane新增btn-preview-save，只有编辑器生成的草稿预览才显示“确认保存这份预览”。普通Agent diff仍只读，展示经escapeHtml转义。大diff区域已有滚动，不插入未转义HTML。验证editorRuntime和浏览器。

文件菜单另有“预览回退本次保存”；diff页的btn-preview-save依据快照类型改为“确认回退这次保存”。没有回退句柄或有未保存草稿时显示拒绝原因，不以旧diff覆盖新草稿。

工具接入页新增ops-public-https复选框，默认关闭。登记公网需外发确认；地址标签不再错误地限定为回环，未知/不支持认证仍明确失败。

## 接入结果独立区域（第36组）

index.html在登记按钮之后加入ops-external-result，pre/url-box与aria-live=polite，只显示文本。登记/移除结果与ops-status列表统计分开，刷新列表不能清掉未知/停止未确认提示；它不是进程退出监控器。workbenchHtml的required清单验证ID存在，实际行为由operations的externalMutation及VM/Chromium回归说明，不以ARIA属性认定完整读屏验收。

第42组：设置Bridge页的bridge-result与右栏bridge-result-rb均为role=status/aria-live=polite，同步展示启停动作结果，不用运行pill代替写入确认。btn-bridge-toggle启动在途转“停止启动”，停止期间暂禁两停止入口；密钥轮换仍独立。旧复制banner在启停时隐藏，启动不自动复制，手动复制入口保留。
