# 工作台HTML与SVG：所有区域、数据属性及真实功能边界

覆盖[index.html](index.html)、[favicon.svg](favicon.svg)。HTML定义节点和初始状态，行为来自[交互绑定](js/交互绑定详解.md)，不把“有按钮”理解成“功能已实现”。

## 1. 文档头与内嵌脚本

DOCTYPE启标准模式；html lang=zh-CN/data-theme=dark，UTF8/viewport/title，favicon与CSS均相对URL。head唯一内嵌script try读取localStorage webagent-theme，仅light/dark写data-theme；异常吞，用默认深色。它在body绘制前运行降低主题闪烁，不启动模型、联网或写盘；后续dom.initTheme负责按钮/Monaco同步。底部script type=module加载app.js及其ES imports。

## 3. 设置弹层所有页面

modal是role=dialog/aria-modal=true、初始hidden；modal-nav各data-page对应page-ID，modal-main滚动，modal-close关闭。已有ARIA并不等于焦点陷阱/恢复焦点/读屏标题都完成。

| page-ID | 字段组/消费者 | 不应误读的能力 |
|---|---|---|
| overview | two-paths说明，pref-input/保存，card-grid导航 | agents卡文字提工具权限，但当前保存name/role，不产生独立ACL；Voice/Dictation disabled，确实未实现 |
| env | env-os/shell/reply/commit/notes，detect/save/status | 探测/声明偏好，不安装Shell或激活Conda |
| stack | st-lang/fw/pm/test/notes，detect/save | 写技术栈文本，不立即安装依赖或跑测试 |
| agents | agents-list、ag-name/role、add | 登记角色，不启动并行Agent |
| skills | skill-templates三data-tpl，skills-list，sk-name/when/steps/body | 生成工作区SKILL.md；&#10;仅placeholder换行，不自动执行步骤 |
| instructions | instr-text/save | 写工作区指令，由Chat/MCP消费者读取 |
| prompts | prompts-list、pr-name/body、add | 模板插入聊天后仍需发送 |
| hooks | hooks-list、hk-event(onSave/onTask)/cmd | 仅记录，不绑文件保存/任务执行钩子 |
| mcp | mcps-list、mcp-name/endpoint | 仅地址清单，不是已接入外部MCP客户端 |
| plugins | plugins-list、pl-name | 仅备注，不加载插件代码；本轮纠正该段损坏字符 |
| api | m-base/key/id/vision、Test/Add/builtin、provider-table | password只隐藏屏显；API key由后端存工作区配置，不是OS钥匙串；m-name隐藏字段当前添加逻辑未读取 |
| codex | codex-status、disabled btn-codex | 未接Codex OAuth，不碰auth.json |
| multimodel | mm-enabled/merge/merge-display/pick/active/think/readonly/branches/save | DOM number min2/max8只是交互提示，后端另验证；合并模型选值需保存 |
| bridge | 下节细分 | 连接指引/授权/隧道，非远程UI |

## 4. Bridge页所有组

br-head展示bridge-sub/pill；client-recipes的cards/detail/pairing-line由status生成，必须按真实客户端连接方式理解。mcp-block含URL/复制与banner，初始hidden；actions切启停/复制prompt/rules/八个open-site。open-site只是本地指引/外链准备，不声明实际登录；prompt-hint说明规则传递，本轮修复“网页”乱码。

授权block区分本机演示与可选GitHub，acct-label/pill/install-id/usage-line由状态填；gh-token密码输入autocomplete off，token/device/clear按钮分别对应API；没有将GitHub身份等同仓库push授权。

连接设置含conn-label/pill和三个name=tunnel radio：cloudflare默认，named的domain/token，ngrok的domain/token。Quick卡on只是初始class，radio选中与on样式不必总同步；vendor限制文字不是服务端强制规则/实时官方查询。

快速打开details含ql-list/name/url/add；高级details实际只有reset-secret按钮。文字提“随启动/timeout”不代表页面已有这些设置控件。所有secret/password输入仍是DOM内明文值，不可据type=password声称加密存储。

## 5. 页尾菜单与图标文件

file-menu data-act：new/open/save/welcome/custom；manage-menu固定三个入口；agent-pick-menu data-mode ask/plan/code+定制入口。class dropdown/hidden配合bind切换，不是浏览器原生应用菜单。toast用原生hidden属性初始隐藏，dom.toast临时展示；不能与.hidden类混为同一个字段。

favicon.svg的viewBox32×32，rect同尺寸rx8紫色背景；一个path含左右尖括号和斜线三段，白色2.2描边、圆端/圆角、fill none；无JS、网络资源或事件。它不同于扩展24px线框icon，不能用改其中一个期待另一处同步。

## 6. 验证与逐断言说明

[workbenchHtml.test.js](../agent-host/tests/workbenchHtml.test.js)是静态文件测试：required数组遍历检查13个关键ID；后续检查四个隧道输入/命令说明、演示授权及禁止旧“未实现ngrok/永久顺/外部Skill无须复制”等文字。检查资源为相对URL而非根绝对路径；主题/健康/统计/WS节点齐全。two-paths三ID及截图签字说明、bind包含两张演练卡；最后检查语义chips、两个模型选择器、chatSrc含branch-pill及Bridge details组。本轮增加禁止U+FFFD替换字符的回归，防止已观察到的乱码返回。

该测试顶层读取HTML/bind/chat，for-of断言，失败抛错；**没有浏览器、点击、CSS尺寸或网络请求**，最后日志“has bind nodes”不能证明每个装饰按钮已接线。

```bat
npm test --prefix webagent-core/agent-host -- --filter=workbenchHtml
npm test --prefix webagent-core/agent-host -- --filter=workbenchRuntime
```

本文件非JS段与内嵌脚本人工解释，登记不冒充AST完整性证明。真实浏览器焦点、输入法、DPI及模型/手机测试继续保留实际验收状态。
