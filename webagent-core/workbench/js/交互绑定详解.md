# bind.js：逐个交互回调与提交数据

[bind.js](bind.js)是页面事件连接层。**onClick(id,handler)**找不到节点就返回，找到赋onclick；**bind()**执行一次大批绑定，最后ui.bind引用它。多数其他直接`$('#id').onclick`要求HTML节点存在，不能把onClick的容错推广到整个文件。

HTTP普遍没有统一res.ok/业务错误/异常捕获包装。下表的“提交/刷新/提示”是实际动作，不保证服务器保存成功；关键后端验证见API详解。本文件不应当被当作授权边界。

## 2. 模型与Chat回调

- model-pick-btn→openModelPicker；**onPick(id)**把候选ID交给model-select.onchange，不乐观修改按钮标签。btn-mm-pick→带mergeMark的picker，onPick仅改待保存merge/display值；btn-mm-active回active，不立即写后端。
- model-select.onchange捕获非空候选ID，立即恢复隐藏select为最近确认的activeModelId，再调用saveModelSettings；等待期间Chat不消费未确认候选。HTTP/业务/网络失败不修改确认快照，成功后的有效刷新统一更新select和按钮。think-select.onchange设dataset.touched，避免refreshStatus覆盖手选。
- btn-send→sendChat()；btn-plan-merge→sendChat('',planAction merge)；btn-agent-send取agent-input和模式再sendChat显式text（不会走sendChat无text清输入分支）。两输入keydown Enter无Shift触发发送，mode-select.onchange更新模式，chips.onclick取data-mode/data-text快捷发送。发送中再次sendChat是取消，不排队。

## 3. Bridge与身份回调

| 控件 | API/动作 | 错误及限制 |
|---|---|---|
| btn-bridge-toggle / btn-stop-bridge-rb | 启动在途优先stop，否则按status选择；右栏直接stop | 启停独立guard、代次与绑定结果消费见Bridge说明；页面锁非跨页幂等 |
| btn-reset-round | resetRound | 清统计不重置全部授权 |
| btn-copy-url/prompt/rules | clipboard.writeText | URL含secret；rules无内容仅提示；提示按客户端适配，没有“已连上”证明 |
| btn-reset-secret | 委托ui.resetSecret | 主逻辑在Bridge说明：确认、绑定/旧密钥复查、在途互斥、坏响应未知；不再无条件toast成功 |
| open-site各按钮 | openSite(data-site) | 本地连接指引，不真实浏览器自动登录 |
| btn-gh-login | POST bridge/login空JSON→loggedIn=true→refreshStatus | 明确演示授权不是GitHub |
| btn-gh-token | POST token，解析后清token输入；success false提示返回 | 成功才刷新并显示username；网络失败在清空前可能保留输入 |
| btn-gh-device | POST device；失败提示；成功显示verificationUri/userCode，安排tick | 不自动填写用户设备码授权 |
| btn-gh-clear | POST github/clear→refreshStatus | 清GitHub身份，提示保留演示授权 |
| btn-refresh-auth | paintBridge+提示 | **不fetch新状态**，只是用当前state重绘 |

设备码闭包 **tick()** POST device/poll→json；done刷新/通知结束，pending setTimeout(tick,5000)，否则提示终结错误。首次按服务端interval或5秒延后。没有前端全局设备码计时器去重/abort，重复点击可产生多个轮询链；网络错误没在tick内catch。

## 4. Skill与定制配置回调

**skillMarkdown(name,when,steps)**trim名称或untitled，description替换换行截200，组装front matter、何时使用/步骤并join；这是普通文本拼接，不是YAML通用安全序列化。SKILL_TPL三个固定模板fix-tests/review/release只产生说明，不自行运行命令。

**fillSkillPreview()**不存在正文框或dataset.dirty=1就返回，否则用三个字段生成。name/when/steps.forEach注册input；正文input标dirty保护手改；skill-templates.onclick找data-tpl、填三个字段、清dirty再生成。

| 控件 | 收集字段与动作 | 副作用 |
|---|---|---|
| btn-add-agent | 旧agents追加Date.now ID/name/role，saveCustom | 登记智能体描述，不启动独立Agent |

## 5. Provider发现与添加

**providerDraft()**在点击时trim读取m-base、m-key、m-id及m-vision.checked，返回本次四字段快照。btn-test-api/btn-save-model分别调用ui.configureProvider(draft,true/default false)，具体期限、共享guard、失败处理和保存契约的唯一主说明见[Bridge与设置详解](Bridge与设置详解.md)。bind不再直接探测后拼builtin+models整表覆盖。

Test只读取列表，不保存。Add在手动ID非空时明确跳过发现，否则发现成功才提交；不因网络/HTTP失败自动转手动或改用内置。后端仅追加、冲突拒绝，保留旧模型/Key及活动模型，不宣称列表成功等于Chat兼容。btn-use-builtin仍须用户明确点击，调用saveModelSettings；false显示未确认，true只确认已保存并提醒刷新失败需核对，不自动重放。

## 6. 文件、终端、搜索与站点栏

- lnk-new-file：prompt名称→PUT files/content(path,content:'')，不带expectedHash/覆盖确认；后端负责已有文件拒绝，随后刷新树/openFile，不主动覆写旧内容。open-file/open-folder只切explorer，并非操作系统选目录对话框。
- term-form.onsubmit：preventDefault、trim非空、清输入/回显，POST tool/call，name run_command、mode code、arguments.command；解析result.stdout/stderr输出。此回调不提供危险确认字段，也未显示所有业务error，故拒绝不等于命令成功但无输出。
- btn-search：query trim后POST search_files/ask，matches.map出文件/行/正文，escape文件与正文（行号依赖后端数值）；search-results.onclick委托openFile。没有分页UI和总结果数提示，也不跳到具体行。
- br-go：读地址，只有当前browser tab才更新url并renderBrowser；br-reload同样重绘。它们不创建真实外部会话、不执行本机Agent任务。

## 受控执行增量

bind新增ui.initOperations绑定本机工具接入与审批；按钮和确认流程逐项见agent-host/src/utils/受控工具与工作流详解.md。

btn-refresh-activity通过可选onClick绑定调用refreshBridgeActivity，只重新同步，不调用reset-round。

文件菜单data-act=preview调用ui.previewActive；保存仍调用ui.saveActive，二者不同。确认预览按钮由tabs.initEditorSafety绑定，不用把所有diff当成可写草稿。验证editorRuntime与workbench.browser的菜单点击流程。

文件菜单data-act=undo-save调用ui.previewUndo，仅预览最近保存的受保护回退；实际确认由tabs的同一diff按钮执行，不绑定自动回退快捷键。

定制设置调用统一检查saveCustom返回值：false立即退出，环境/技术栈状态、指令/偏好/智能体成功toast只在确认成功后更新。失败细节与草稿保留由settings处理，不自动重试；该约束不表示所有其他fetch按钮已审完。

多模型保存按钮通过saveModelSettings统一检查HTTP/业务失败与未知状态，移除无条件“已保存”提示；失败保留输入。模型表格选择使用同一页面内互斥；其他模型新增/状态刷新调用仍单独审查。

第三方候选的复制地址toast提醒先核对版本、认证与兼容性；复制仍只是本机剪贴板操作，不自动建立会话、注入规则或授权工具。

复制提示词先检查promptText结果，空值不写剪贴板、不显示成功；OAuth连接器的菜单/账户支持需按版本核对，不依旧ChatGPT菜单文案操作。
