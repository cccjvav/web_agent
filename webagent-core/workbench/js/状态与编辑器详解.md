# 工作台状态、DOM、编辑器与模型选择器

覆盖[state.js](state.js)、[dom.js](dom.js)、[tabs.js](tabs.js)、[monaco.js](monaco.js)、[picker.js](picker.js)。这些是浏览器ES module，不是CommonJS；[app.js](../app.js)import后，ui对象收集兄弟模块能力，减少循环导入。

## 1. state.js

**$(s,el=document)**querySelector首个节点/null；**$$(s,el=document)**把querySelectorAll转数组以便map/filter。调用者若未检查null就访问属性，缺少HTML节点会抛错。

state是共享可变对象：mode/status控制模式和服务端快照；messages/history是显示事件和模型文本历史，不相同；sending是并发门禁；tabs/activeTab从欢迎页起步；editor为Monaco实例，files/monaco/dirty等保留字段不意味着每条路径都使用。stats记录页面收到的事件，非完整服务器计费账本；loggedIn初始true指演示状态，后续服务器可改；custom/stayOnBridge/selectedClient/planRound供设置和流程。SITES是八个站点的名称/URL目录，不会自动安装或登录这些服务。ui初始空对象，模块顶层赋函数引用，实际使用必须等import执行完。

## 2. dom.js全部函数

| 函数 | 参数/返回 | DOM/存储副作用与边界 |
|---|---|---|
| applyTheme(theme) | theme→实际light/dark | 只light算浅色；写document dataset、尝试localStorage，更新按钮文本/aria，存在window.monaco则切编辑器主题 |
| initTheme() | 无→主题 | 读取存储失败默认dark，委托applyTheme |
| toast(text) | 文本→undefined | 显示#toast、清上次toast._t，2.2秒回调隐藏；后一次覆盖前一次提示 |
| escapeHtml(s) | 任意→字符串 | replace回调转义&、尖括号、两种引号，供HTML文本/带引号属性；不是URL协议验证 |
| renderMd(src) | Markdown子集→HTML | 先escape再正则code/bold/标题/列表/换行；不是完整Markdown解析器，多轮正则可能干扰代码块格式，但不直接信任源HTML |
| termLine(text,cls='') | 文本/类→undefined | createElement+textContent附加#terminal并滚动；没有总行数上限 |
| openModal(page) | 页名→undefined | 显示弹层，showPage默认overview |
| closeModal() | 无→undefined | 加hidden，不取消表单请求 |
| showPage(id) | 页名→undefined | 两个forEach切nav on和page hidden |
| setRight(which) | chat/bridge→undefined | 两个页签与两个区域class切换，不启动Bridge/聊天 |

所有导出在底部挂ui同名属性，没有额外包装执行。

## 3. tabs.js状态与全部函数

| 函数 | 输入/返回 | 实现 |
|---|---|---|
| paintTabs() | 无→undefined | 清容器，forEach建立标签；标题escape、脏点标记；标题onclick激活，x回调停冒泡并close；find当前后更新窗口/底栏/document.title |
| captureActiveFile() | 无→undefined | 当前file才取model.getValue或textarea，Monaco保存viewState，内容与savedContent比较dirty；只捕获当前，不写盘 |
| initEditorSafety() | 无→undefined | safetyBound保证只绑一次；textarea input捕获+重画；beforeunload捕获，some dirty/saving则preventDefault/returnValue请求浏览器确认 |
| activateTab(id) | ID→undefined | 先捕获旧文件再改activeTab，按kind切五种面板，file applyEditor/browser ui.renderBrowser/diff paintDiff，最后paintTabs |
| closeTab(id) | ID→undefined | 先捕获；不存在或只剩一个不关；saving提示等待；dirty确认；活跃标签先解除editor.model；dispose listener/model，filter删除，再选最后一个或重画 |
| openAgentWindow() | 无→undefined | find或push固定agent tab，切右Chat、激活并paintChat |
| openDiff(filePath,diff) | 路径/差异→undefined | diff:路径固定ID，新增或替换diff文本后激活；不是可保存编辑文件 |
| paintDiff(tab) | tab→undefined | path textContent，split/map行判增删/hunk，escape后innerHTML；只是差异文本展示 |
| ensureWelcome() | 无→undefined | 缺welcome就unshift，激活；不丢弃其他标签 |
| openFile(filePath) | 路径→Promise<void> | 已有则激活；否则GET编码path，检查res.ok、content字符串与64位hash；请求返回后二次find防重复标签，创建content/savedContent/hash；catch toast |
| langFor(p) | 路径→Monaco语言名 | 仅.js/.json/.md/.css/.html精确后缀，其他plaintext，不分析内容 |
| applyEditor(tab) | tab→undefined | Monaco可用则懒建model，onDidChangeContent更新content/dirty并重画；setModel/restoreViewState；否则填textarea |
| treeHtml(items,depth=0) | 嵌套列表→HTML | map递归children构目录/文件，depth控制缩进，name/path escape；没有客户端深度限制，依赖API控制 |
| loadTree() | 无→Promise<void> | GET tree/json，生成树、目录折叠onclick；文件onclick openFile；内部walk递归收文件，前6个渲染“最近”列表及委托打开回调——实际上是遍历前6，不是真实访问历史 |
| saveActive() | 无→Promise<void> | 见下节版本流程 |

**saveActive保存流程**：capture→find文件/非saving→验证hash→截取本次content快照、saving=true→PUT path/content/expectedHash。409明确磁盘冲突不覆盖；要求HTTP成功且data.success=true以及返回有效hash。成功更新tab.hash和savedContent为**本次提交正文**，再capture，后续仍有编辑则dirty保留。finally清saving重画。

用户保存中可以切标签；保存对象用闭包tab保留，避免写错目标。captureActiveFile取的是当前活跃项，因此后台tab内容还依赖其Monaco变更/离开前捕获。返回缺hash即使磁盘可能已写也提示核查，不谎称事务回滚。loadTree未统一检查res.ok、catch由调用者决定；新文件不是此函数保存流程，而由bind发送无hash创建请求。

## 4. monaco.js：loadMonaco()

**loadMonaco()**返回Promise<boolean>，先用内部**show(text)**更新状态。**finish(ok)**每次更新文字，但settled只允许Promise resolve一次，并清timer。7秒timer按当前state.editor判断加载结果。

创建远程固定版本0.52.2 AMD loader script；onerror finish(false)；onload try配置vs路径，require模块。成功回调先ui.captureActiveFile保存纯文本编辑，再create editor(model:null、自动layout等)，激活当前标签，finish(true)；require失败/创建异常false。script附head后才加载。

超时没有取消脚本或禁止后来创建editor，所以Promise可能先false后UI仍成功升级；finish后续也更新状态文字。纯文本fallback是可用编辑器，不是模型自动回退。CDN不可达应继续安全编辑，不能因此要求用户关闭浏览器全部安全设置。

## 5. picker.js全部函数/闭包

**closePicker()**移除openBox并置null；**closeModelPicker()**公开包装。**openModelPicker({anchor,currentId='',onPick,mergeMark=false})**先关旧弹层，从status.models排除builtin，建搜索框/列表。

内部**paint(q)**小写filter name/id/modelId/group，rows.map生成按钮；caps副本按some检测补vision；mergeMark且currentId相同加当前合并模型标识；所有动态文本/属性escape。oninput重新paint；onkeydown Escape关；list.onclick closest有效按钮，先关再onPick(id)。不自动保存模型，onPick由bind提供。

用anchor rect和窗口计算fixed left/top后append，openBox赋值；**away(e)**外部mousedown关并卸载自己，setTimeout下一tick才注册，避免打开时同次点击关掉。其他关闭路径不统一remove该监听，因此可能留旧away回调；不要把closePicker描述成完整事件资源清理。模型列表是打开时快照，刷新status不会自动更新当前弹层。
