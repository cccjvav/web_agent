# 工作台状态、DOM、编辑器与模型选择器

覆盖[state.js](state.js)、[api.js](api.js)、[vscodeRelay.js](vscodeRelay.js)、[dom.js](dom.js)、[tabs.js](tabs.js)、[monaco.js](monaco.js)、[picker.js](picker.js)。这些是浏览器ES module，不是CommonJS；[app.js](../app.js)import后，ui对象收集兄弟模块能力，减少循环导入。

## 1. state.js

**$(s,el=document)**querySelector首个节点/null；**$$(s,el=document)**把querySelectorAll转数组以便map/filter。调用者若未检查null就访问属性，缺少HTML节点会抛错。

state是共享可变对象：mode/status控制模式和服务端快照；messages/history是显示事件和模型文本历史，不相同；sending是并发门禁；tabs/activeTab从欢迎页起步；editor为Monaco实例，files/monaco/dirty等保留字段不意味着每条路径都使用。stats记录页面收到的事件，非完整服务器计费账本；loggedIn初始true指演示状态，后续服务器可改；custom/stayOnBridge/selectedClient/planRound供设置和流程。SITES是八个站点的名称/URL目录，不会自动安装或登录这些服务。ui初始空对象，模块顶层赋函数引用，实际使用必须等import执行完。

## 1a. api.js：统一请求入口（R6第二期第一批）

工作台所有模块向本机主机发HTTP请求都经这里；bind、bridge、chat、operations、settings、tabs六个模块原有33处`fetch(`已机械替换为`apiFetch(`，参数与返回值不变。

**apiFetch(input,init)**：未安装转发函数时直接`globalThis.fetch(input,init)`，参数原样传递；每次调用时才读取`globalThis.fetch`，不在加载时抓住引用，因此替换`window.fetch`的测试与浏览器回归照常生效。安装了转发函数时改为调用它。

**setApiTransport(fn)**：安装转发函数；`fn(input,init)`须返回fetch Response（或模块已消费的同形对象）的Promise；传null恢复直连fetch，其他类型抛TypeError。网页工作台从不调用它，行为与改造前一致；供第二期插件设置页把同样的请求经`postMessage`交给扩展进程转发，webview自身不访问127.0.0.1，也不放宽主机Origin检查。

守卫：workbenchRuntime扫描工作台全部模块与app.js，除api.js外不得出现裸`fetch(`，用到apiFetch的模块必须从`./api.js`导入（同一个转发函数实例）；并验证参数原样、按调用查找、转发与恢复，以及真实bridge.refreshBridgeActivity在安装转发后只走转发。

## 1b. vscodeRelay.js：设置页的转发函数（R6第二期第2批）

只有插件设置页入口加载它，网页工作台app.js不导入，仍用直连fetch。**createRelayTransport({postMessage,onMessage,makeResponse})**订阅扩展回复并返回转发函数**relayTransport(input,init)**，交给setApiTransport。发往扩展的只有method（大写）、path和body；headers、cache等不外传。回复遵循fetch语义：只有明确`ok:true`才用**defaultResponse**构造Response（101/204/205/304不带正文，带content-type）解析为回答，任何HTTP状态都是回答；拒绝、网络失败、期限与缺少ok的回复都以TypeError拒绝；postMessage本身抛错立即清理并以TypeError拒绝。取消：信号已取消则不发送、直接以**abortError**（DOMException AbortError，无DOMException时退回同名Error）拒绝；在途取消由**onAbort**发`webagent-api-abort`并拒绝，迟到的回复按编号丢弃。编号为随机前缀加序号。

## 4. monaco.js：loadMonaco()

**loadMonaco()**返回Promise<boolean>，先用内部**show(text)**更新状态。**finish(ok)**每次更新文字，但settled只允许Promise resolve一次，并清timer。7秒timer按当前state.editor判断加载结果。

创建远程固定版本0.52.2 AMD loader script；onerror finish(false)；onload try配置vs路径，require模块。成功回调先ui.captureActiveFile保存纯文本编辑，再create editor(model:null、自动layout等)，激活当前标签，finish(true)；require失败/创建异常false。script附head后才加载。

超时没有取消脚本或禁止后来创建editor，所以Promise可能先false后UI仍成功升级；finish后续也更新状态文字。纯文本fallback是可用编辑器，不是模型自动回退。CDN不可达应继续安全编辑，不能因此要求用户关闭浏览器全部安全设置。

## 5. picker.js全部函数/闭包

**closePicker()**先运行并清空**disposePicker()**，取消延迟timer并移除mousedown/keydown/scroll/resize监听，再移除openBox；**closeModelPicker()**公开包装。**openModelPicker({anchor,currentId='',onPick,mergeMark=false})**先关旧弹层。聊天选择器保留builtin；只有mergeMark合并选择器排除builtin，避免把本机探索伪装成外部合并模型。

内部**paint(q)**小写filter name/id/modelId/group，rows.map生成按钮；caps副本按some检测补vision；mergeMark且currentId相同加当前合并模型标识；所有动态文本/属性escape。内置行明确“无需 API Key（非通用大模型）”；区分无搜索匹配、未配置外部合并模型和状态尚未加载。oninput重新paint；list.onclick closest有效按钮，先关、恢复anchor焦点，再onPick(id)。不自动保存模型，onPick由bind提供。

append后调用positionPopover，再聚焦搜索框。**away(e)**忽略弹层和anchor内部点击；**escape(e)**阻止Escape继续冒泡到窗口关闭设置页，关闭并恢复按钮焦点；**scroll(e)**只在弹层外滚动时关（弹层内部必须可滚）；窗口resize也关闭。setTimeout下一tick注册外部mousedown，所有关闭路径均取消未执行timer并卸载已注册监听，反复重开不会遗留旧实例。模型列表仍是打开时快照，刷新status不自动重画已打开弹层。

## 已有文件的预览与确认保存

**previewActive()**先捕获当前草稿，忽略非file、saving或previewing；POST /api/files/preview发送path/content/expectedHash。没有PUT，所以预览不保存。await后重新capture并检查原tab仍存在且仍活动、正文/hash没变；变化则丢弃旧响应不抢焦点。核对服务端path/hash和diff类型后openDiff，附原tab引用、正文和hash快照。finally释放previewing。

**savePreview()**只接收当前diff页的preview；源tab被关闭、正在保存、正文或hash变化则不发请求，要求重新预览。提交前消费preview并隐藏确认按钮，再调用saveFile保存快照；即使响应丢失也不能双击重放。保存时仍校验磁盘hash，不依赖预览时的旧结论。initEditorSafety同时绑定btn-preview-save，文件菜单由bind接previewActive。普通Ctrl+S路径保留，不强制每次弹预览。

验证editorRuntime覆盖仅POST、显式保存、一次消费、草稿漂移与异步预览过期；apiFiles覆盖真实HTTP无写入及预览后磁盘漂移409；workbench.browser通过实际菜单和按钮检查磁盘内容。仅经典工作台已有文本文件，不是跨文件事务、自动回退或VS Code原生diff整合。

## 单次保存的回退预览

**previewUndo()**捕获文件，拒绝saving/previewing、dirty或无undo.id；GET /api/files/undo/:id，await后复查同标签/正文/hash/句柄，再openDiff并附undo字段。失败toast且不写盘，finally清previewing。saveFile保存响应的data.undo（或null）；刷新/关闭标签不恢复句柄。

savePreview消费快照后根据undo分流：普通预览saveFile；回退时源saving=true、清undo，POST confirmed/expectedHash/workspaceRoot/hostInstanceId。成功需path/content/hash匹配格式；更新savedContent/hash，只有source.content仍等于提交时内容才覆盖缓冲区，后续草稿保持dirty。finally清saving重画；未知结果不重放。paintDiff按undo切“回退预览，尚未执行”及确认文案，普通工具diff仍不可保存。验证editorRuntime覆盖期间编辑/脏稿拒绝，API与浏览器另验。

F54第六批：closeTab仍先捕获草稿，保留saving阻止、dirty确认、最后一页不关闭及model释放；成功关闭后聚焦剩余活动tab。关闭按钮由逐页内嵌改成tablist外的“关闭当前页”，关闭非当前页须先选择；也可在选中页签按Delete。不是忽略ARIA错误或用嵌套button规避规则。
