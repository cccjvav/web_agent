# code-server准备、认证与双进程编排

覆盖[ensure-code-server.js](ensure-code-server.js)、[codeServerAuth.js](codeServerAuth.js)、[run-code-oss.js](run-code-oss.js)、[install-desktop-extension.js](install-desktop-extension.js)。这是可选网页VS Code/桌面扩展路径，不等同主安装器的Program Files+用户运行目录设计。此处旧编排仍有仓库相对写入位置，不能据此改写已确认的Windows安装布局。

## 1. ensure-code-server.js全部函数

VERSION固定4.135.0，repoRoot为仓库根，runtimeRoot为bin/code-server-runtime；本文件被require时不会自动下载，CLI分支才ensure+syncExtension。

| 函数 | 参数/返回 | 实现/失败 |
|---|---|---|
| npmCmd() | 无→命令名 | Windows npm.cmd，否则npm |
| runNpm(args,cwd) | 参数数组/目录→undefined | spawnSync继承终端/环境，加FORCE_NODE_VERSION主版本；Windows shell；非零或null status抛错，无timeout |
| findEntry() | 无→路径/null | candidates.find依次npm布局/版本目录/Linux-amd64目录；只是存在性检查 |
| vscodeDirFromEntry(entry) | entry→目录 | 从out/node回到lib/vscode；不扫描任意安装 |
| ensureVscodeDeps(entry) | entry→undefined | @microsoft/1ds-core-js marker存在即跳过；无package.json报不完整；否则npm install omit-dev/ignore-scripts等。marker不是全部依赖校验 |
| ensure() | 无→entry | mkdir runtime，找不到entry才建缺失package.json并npm install固定code-server；再次找不到抛错；ensureVscodeDeps后返回，不证明平台可运行 |
| extensionVersion() | 无→字符串 | 读extension/package.json，错或空回0.6.9 |
| syncExtension() | 无→dest | 版本目录mkdir；循环源根文件仅复制package.json与.js，icon存在才复制；写extRoot/extensions.json登记单个扩展，返回dest |

syncExtension不是通用copyTree：不复制所有Markdown/子目录、不删除目的地陈旧文件；extensions.json按单元素数组重写。既有extensionCopy测试要求仓库内副本清单一致，新增讲解另行同步副本，并不意味着这里的运行时同步会自动带上讲解。CLI try/catch打印entry或错误并exit1。

## 2. codeServerAuth.js全部函数

**trustedOrigins(port)**Number(port)或3000，返回127.0.0.1/localhost两HTTP origin逗号串；没有公网预览域名，也不支持自动wss推断。因此此可选启动器默认本机使用，不拿它直接作为Arena预览服务。

**resolveAuth({userData,env=process.env}={})**读取CODE_SERVER_AUTH，只有none显式无密码，否则password。目录默认仓库.local/share/code-server，passwordFile=webagent-password；CODE_SERVER_PASSWORD非空优先返回（**并不在这个分支写文件**）；否则尝试读现有非空文件；最后randomBytes(12).base64url生成、mkdir、write mode0600并返回。

已有文件读取错误被吞，若随后写失败会抛错；写入非原子/无锁，不保证并发首次生成一致。0600不等价完整Windows ACL。返回password字段为敏感值，运行器当前会打印；分享日志前要去掉，不把这些文件提交Git。CODE_SERVER_AUTH=none是用户显式配置，不是默认模式。

## 3. run-code-oss.js全部函数与启动副作用

顶层从argv[2]/WORKSPACE_ROOT/默认workspace选路径，端口parseInt；工作区不存在立即exit1；文件尾无require.main保护，require也会运行main，不适合作纯工具模块导入。

**waitHealth(url,timeoutMs)**返回Promise。内部**tick()**http.get，响应res.resume释放body；status200 resolve，非200且elapsed超限reject，否则200ms setTimeout(tick)。error回调同样超限或重试。没有给单个HTTP请求设置超时，所以某连接一直不响应时总期限不是硬超时保证，也无AbortSignal。

**run(command,args,opts)**spawn stdio inherit/windowsHide，显式opts.shell/cwd，环境浅合并；child.error打印后process.exit1；返回child，不await存活/健康。

**main()**：打印横幅→ensure下载/准备→syncExtension→express marker缺失时npm install；安装Promise的child.exit仅code0 resolve，否则reject。此安装子进程还没加入后续children列表。

内部**stop()**遍历children，缺/已killed跳过；Windows spawn taskkill /t /f，其他SIGTERM，异常吞；没有await退出或Unix进程树组回收保证。SIGINT/SIGTERM回调stop后立即exit0。

启动agent-host用当前Node、src/index.js、WORKSPACE_ROOT/AGENT_HOST_PORT/WEBAGENT_SKIP_WORKBENCH=1；children.push，agent.exit只有非零code才stop并exit，code0不在该回调关code-server。await 15秒waitHealth后创建userData、resolveAuth；config路径仍仓库.config/code-server/config.yaml。

code-server参数包含auth/bind（默认127.0.0.1）、disable telemetry/update、trustedOrigins、app名、userData/extensions/config/workspace。密码模式用PASSWORD环境传给子进程，控制台打印密码与passwordFile（环境密码分支未必实际写该文件）。code-server.exit不论成功失败都stop，process.exit(code||0)。最外main.catch仅打印/exit1，没有显式stop闭包可访问，启动中后续失败的清理不能等同隧道stopProcess实现。

## 4. install-desktop-extension.js全部函数

| 函数 | 参数/返回 | 作用与边界 |
|---|---|---|
| readManifest() | 无→publisher/name/version/folderName/id | 解析源package.json，缺字段给默认；JSON坏直接抛，不按路径安全规范校验publisher/name |
| copyTree(from,to) | 两目录→undefined | mkdir，readdir循环；名README.md任何层跳过；stat目录递归否则copyFile；跟随符号链接语义，目的地旧文件不清 |
| pruneOld(extensionsDir,keepName) | 目录/保留名→removed数组 | 只匹配固定webagent.webagent-core-前缀且非keepName才rm recursive/force，避免删其他扩展；如果manifest改publisher/name，固定前缀不自动跟变 |
| defaultExtensionDirs() | 无→目录数组 | WEBAGENT_VSCODE_EXTENSIONS优先唯一resolve路径；否则home/.vscode/extensions；检测.vscode-insiders存在才加其目录 |
| installTo(extensionsDir) | 目录→dest及manifest | read→mkdir→copyTree→pruneOld→返回；复制失败不会先删旧版，但已存在同版目的地可能部分更新，非事务安装 |
| installAll(dirs=defaultExtensionDirs()) | 数组→结果数组 | dirs.map(installTo)，同步顺序执行，中间失败抛，前面安装不回滚 |

CLI require.main保护内try installAll，逐结果打印路径，说明启动agent-host/重载VS Code/打开同工作区；catch打印并exit1。此脚本不启动VS Code、不为用户自动激活Conda、不判断目标编辑器版本真的合格。
