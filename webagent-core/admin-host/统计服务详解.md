# Admin统计服务：逐函数、路由与持久化

覆盖[app.js](app.js)、[index.js](index.js)。这是可选用量收集器，不是控制工作区的MCP服务。调用方是agent-host/usage/tracker；共享Bearer只授权上报/看统计，不是GitHub OAuth签名证明。

## 1. 文件与令牌辅助函数

| 函数 | 输入/输出 | 状态与失败 |
|---|---|---|
| defaultDataDir() | 无→目录 | WEBAGENT_ADMIN_DATA优先，否则本目录data；不是主安装器用户runtime自动映射 |
| reportsFile(dataDir) | 目录→reports.json路径 | 仅path.join |
| tokenFile(dataDir) | 目录→admin-token.txt路径 | 仅path.join |
| ensureToken(dataDir) | 目录→令牌字符串 | 先mkdir；环境token trim非空优先；否则读已有非空文件；读错吞；randomBytes16转hex，写文件后尝试chmod0600，chmod错吞 |
| loadReports(dataDir) | 目录→数组 | read+JSON，非数组或任何错误→空数组；不校验每行字段 |
| saveReports(dataDir,rows) | 目录/数组→undefined | mkdir后同步整文件JSON写入，无临时rename、版本检查或跨进程锁 |
| today() | 无→YYYY-MM-DD | ISO截前10，UTC日期而非用户本地时区 |

ensureToken不打印正文；环境token分支不会写文件。文件权限0600在Windows不等同完整ACL配置。loadReports坏文件退空后，下次ingest可能覆盖旧文件，因此不能套用模型store的“坏配置保留”保证。

## 2. ingest与排名

**ingest(dataDir,body)**：installId字符串trim非空，否则抛status400；day默认today并截10（未严格验证日期）；githubUser去首@再trim；组装rec，toolCalls/fail用Number及Math.max下限0，successRate缺省null，否则Number；lastAt可由上报者给，reportedAt始终当前ISO。provider/product/version/GitHub ID也保存。

loadReports.filter剔除同installId且同day记录，再push新rec/save，返回rec。是**同安装同日快照覆盖**，不是每次上报累计相加。同步读改写在单Node事件回调中不跨await，但没有多个进程间锁。数值没有完整finite/上限/失败数≤总数验证；JSON.stringify对非有限数的表示也不能被当作数据有效性检查。

**rankDay(rows,day)**：只看同日，GitHub名小写构gh:key，否则id:installId；Map按reportedAt或lastAt的字符串排序保留最新一条。**同GitHub多个安装取最新，不求和、不是取调用次数最多**。然后sort调用量降序、同量按用户名/安装ID localeCompare；map添加rank，缺successRate且toolCalls非零才由fail推算百分比；没有额外clamp。返回只选排名字段，不返回原报告所有元数据。

## 3. HTML及CSS

**escapeHtml(s)**转义&、尖括号、双引号，不转单引号；当前动态用户名/日期主要用在文本区。**renderPage(rows,day)**先rankDay；ranked.map构每行，用户名有则@name，否则“未绑定”+installId；null成功率显示破折号；时间T换空格截19；空表给colspan5提示。返回完整HTML，不依赖浏览器脚本。

嵌入CSS：:root统一字体/前景，body背景，main最大960px与留白；h1/lead分标题说明；toolbar flex+pill日期；table折叠边框，th/td间距和顶对齐；num等宽数字；last-child去尾边；local/sub/empty表示未绑定、安装ID和空结果。它们只改变外观，不产生认证/排序逻辑。

页面“每15分钟”是客户端调度说明，服务端不主动向客户端拉数据，也不强制15分钟节律。页面不含登录表单，普通地址栏访问无法自动带Bearer；受保护不是“本机排行榜不需要令牌”。

## 4. HTTP辅助函数

**readBody(req,maxBytes=1MiB)** Promise：data累计Buffer长度；超限创建status413交内部**fail(err)**，done防重复reject，不再保存超限chunk；end若done返回，否则concat/UTF8，空正文resolve{}，JSON失败reject；error→fail。超限不主动destroy连接；没有本函数内慢请求期限，也不校验Content-Type。

**bearer(req)**大小写不敏感识别Bearer前缀并trim正文，其他空字符串。**timingSafeEqualString(a,b)**转UTF8 Buffer，长度不同false，相同用crypto.timingSafeEqual；隐藏不了令牌长度。**tokenOk(req,token)**组合这两者。**unauthorized(res)**写401 JSON并end，没有浏览器登录重定向。

## 5. createHandler与handle全部分支

**createHandler({dataDir,token})**返回异步具名**handle(req,res)**闭包。先new URL、设Cache-Control:no-store，再进入try；URL解析位于try外，不可声称所有异常都经下面catch。

| 请求 | 授权 | 处理/返回 |
|---|---|---|
| GET /health | 不需要 | 200 {ok:true,product}，不泄露统计/令牌 |
| GET / 或 /index.html | Bearer | day query或UTC今天→loadReports/renderPage，200 HTML |
| GET /api/stats | Bearer | day→rankDay，200 JSON |
| POST /api/report | Bearer，先检查再读正文 | await readBody→ingest→200 success/rec |
| 其他路径/方法 | 不进入上述受保护操作 | 404 JSON |

try内异常用err.status或500和err.message输出；坏JSON通常500而非自动400。所有路径都不缓存；无自动分页、归档、上报频率限制或凭据轮换端点。

**createServer(opts={})**选择dataDir、opts.token或ensureToken，createHandler→http.createServer，返回server/handler/dataDir/token便于测试注入；还没有listen。

## 6. index.js入口

顶层读取端口WEBAGENT_ADMIN_PORT默认4174、绑定WEBAGENT_ADMIN_BIND默认127.0.0.1；createServer后listen。listen匿名回调打印绑定/本机访问提示/数据目录；未设置环境token时打印token文件位置而非正文，末尾void token仅避免未使用。没有require.main保护；require入口也会监听。无显式error监听与SIGTERM异步清理协议。

逐断言解释见[统计与文档测试详解](../agent-host/tests/统计与文档测试详解.md)。该测试证明覆盖写入、排序、Bearer门禁与超大正文拒绝等，不证明数据文件原子性、跨进程并发、真实GitHub身份或长期大量数据性能。
