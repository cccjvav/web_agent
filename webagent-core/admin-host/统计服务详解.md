# Admin统计服务：逐函数、路由与持久化

覆盖[app.js](app.js)、[index.js](index.js)。可选用量收集器，不控制工作区；调用方是agent-host/usage/tracker。共享Bearer授权上报/看统计，不证明GitHub身份或计费真实性。

## 1. 路径、令牌与记录校验

| 函数/常量 | 输入/输出 | 状态与失败 |
|---|---|---|
| defaultDataDir() | 无→目录 | WEBAGENT_ADMIN_DATA优先，否则本目录data；不是主安装器用户runtime自动映射 |
| reportsFile(dataDir) | 目录→reports.json路径 | 仅path.join |
| tokenFile(dataDir) | 目录→admin-token.txt路径 | 仅path.join |
| ensureToken(dataDir) | 目录→令牌字符串 | 先mkdir；环境token trim非空优先；否则读已有非空文件；读错吞；randomBytes16转hex，写文件后尝试chmod0600，chmod错吞 |
| corruptStore(file,reason) | 路径+原因→Error | 构造`code='E_STORE_CORRUPT'`、`status=500`的错误；消息说明原文件原样保留，不含库内容 |
| validDay(value) | 值→boolean | 要求`YYYY-MM-DD`字面量且能往返解析成同一天，排除`2026-02-31`这类可被Date接受却不存在的日期 |
| reportString(value,required) | 值→boolean | 字符串、UTF-8不超过256字节、不含控制字符；`required`时还要求非空白 |
| validReport(row) | 行→boolean | 逐字段校验：installId必填、day合法、toolCalls/fail为非负安全整数且`fail<=toolCalls`、successRate在0..100、其余已知字段满足reportString、时间字段必填且可解析 |
| loadReports(dataDir) | 目录→数组 | 初次ENOENT或全空白→`[]`；观察到文件后，非普通文件、读取失败、坏JSON、顶层非数组、行数超上限或**任一行validReport失败**→抛corruptStore |
| saveReports(dataDir,rows) | 目录/数组→undefined | 先按行数与字节上限拒绝超预算内容；mkdir后写带pid+随机后缀的临时文件（`wx`不覆盖同名、`mode 0600`不让临时副本世界可读），rename原子发布；写入或rename失败统一包成corruptStore（不泄露原始EIO/EACCES），finally清理残留；无版本检查或跨进程锁 |
| today() | 无→YYYY-MM-DD | ISO截前10，UTC日期而非用户本地时区 |

ensureToken不打印正文；环境token分支不会写文件。文件权限0600在Windows不等同完整ACL配置。

**损坏即拒绝。** 以前loadReports把任何读取/解析失败都当成空库，于是一个截断或被别的程序写坏的`reports.json`会在下一次ingest时被一条新记录整体覆盖，历史统计不可恢复。现在区分三种情况：文件不存在或零字节＝合法的空库；能读到内容却不是JSON数组＝损坏，读写都抛`E_STORE_CORRUPT`并且**一个字节都不改**，由运维自己检查或还原。这与模型store的"坏配置保留"是同一条口径。它保护的是"不被本程序覆盖"，并不能恢复已经损坏的内容，也不防止别的进程继续写这个文件。

## 2. 持久化与ingest

**loadReports(dataDir)**：初次lstat确实ENOENT才返回[]。观察到文件后，链接/目录、读取失败、随后消失、坏JSON、非数组、非法已知字段或预算超限一律`E_STORE_CORRUPT`（合并自01a0c932的逐行校验，错误码沿用本分支携带文件名与原因的版本）；不会把损坏当空表。readBoundedJsonText对已打开文件有界读取、严格UTF-8解码并剥掉前导BOM（`JSON.parse`不接受U+FEFF，而文本读取按合同必须保留它）。旧记录未知附加字段不删除；已知字段/接收时间损坏则整表拒绝，不能静默过滤坏行后覆盖。

**saveReports(dataDir,rows)**：先序列化并核对4MiB/10000行；mkdir后写同目录随机.tmp.文件，wx排他/0600，再rename发布；失败包装固定存储错误，finally经共享removeScratch清临时文件（清理失败不会顶替原发布错误，见utils函数详解）。未发布时旧reports.json保持原字节。没有自动备份/自动恢复/跨进程锁/fsync断电事务；应单实例持有目录。损坏时先人工备份原文件再明确修复/恢复，不用清空文件作为静默“修复”。外部进程并发改文件仍可能竞态，本包不认证该场景。

**ingest(dataDir,body)**：先拒绝null/数组/未知字段；仅允许installId、githubUser、githubId、provider、day、toolCalls、fail、successRate、lastAt、product、version。内部bad()生成固定E_BAD_ARGS/status400，不回显输入。day/计数仅省略时取今天/0，显式null计数或日期不当0；rate可null表示未知，其它元数据的空值按兼容缺省处理，lastAt缺省取当前ISO。reportedAt由服务端生成。

组装rec→validReport→trim安装ID/去GitHub首@；任何非法字段在读取/写入存储前拒绝。通过后loadReports.filter剔除同installId/day，再经rotateReports得到待发布数组交saveReports。是**同安装同日快照替换**，不是累加请求次数。同步读改写不跨await，但不是多进程数据库。

**rotateReports(rows,incoming)**（F70）：健康账本到达10000行或4MiB时**轮转最旧的日期**，而不是拒绝上报。此前实测：第10000行之后saveReports拒绝发布，于是**所有客户端、以后每一天**的上报都永久500/E_STORE_CORRUPT，尽管文件并没有损坏。规则：未超预算原样返回[...rows,incoming]（不改顺序、不多余排序）；超预算时按day、reportedAt升序整日删除最旧日期，仍在的日期排名保持完整；只剩一个日期且仍超预算时才删该日最旧的行；incoming（本次上报、ingest以200返回的那条）永不被删，即使它的day比留存的都旧。字节核算一次算清：**rowBytes(row)**用`JSON.stringify([row],null,2)`减去外层4字节得到该行在美化数组中的精确长度，最终大小=4+incoming+Σ(行+2字节分隔)，循环内**fits()**同时检查行数与字节；实测与真实序列化结果逐字节相等。只在loadReports已通过全部校验的账本上运行；损坏账本仍在此之前fail closed并保留原字节。被轮转掉的日期不会再出现在/api/stats，没有自动归档——需要长期留存应外部备份reports.json。

**rankDay(rows,day)**：同日记录以小写GitHub名或安装ID分组，按reportedAt（兼容lastAt）字符串保留最新；同GitHub多个安装取最新，不求和、不取调用量最高。随后按工具数降序、同量按名字排序，map添加rank。缺rate且工具数非零时由fail推算；否则保留自报rate。公开只投影排名字段。

## 3. HTML、字号与布局

**escapeHtml(s)**转义&、尖括号和双引号；当前动态字段放文本区，不作为单引号属性脚本。**renderPage(rows,day)**先排名再生成完整静态HTML：用户名或未绑定/安装ID、次数、成功率、接收时间；null成功率显示破折号，空表colspan5。

CSS：main最大960px，标题22px，说明/正文14px、表头13px、安装ID12px，行距1.5；次要文字用更深的#57606a。table最小620px，不把列强压成不可读的字堆；由.table-scroll局部横向滚动，带region名称、tabindex和可见焦点。窄屏600px以下减少页边距，显示.scroll-hint；长安装ID在240px内折行。表头scope=col且不拆行。键盘方向键可以滚动表格，不让整个320px页面向右膨胀。

“每15分钟”描述客户端周期；调用还会延后触发上报，不是服务端定时拉取或“随身份校验”发送。页面明确自报而非计费/可信审计。无登录表单：普通地址栏不会自动附Bearer，不应把token放公开URL。

## 4. HTTP辅助与handler

**readBody(req,maxBytes=1MiB)**逐块计Buffer字节；内部fail(err)用done防重复reject，后续data不再保存。超限413，空正文{}，坏JSON固定400/E_BAD_ARGS，不回显原正文。error→fail；没有本函数内慢请求总期限，也未新增Content-Type校验或频率限制。

**bearer(req)**识别大小写不敏感Bearer并trim；**timingSafeEqualString(a,b)**比较UTF-8长度后timingSafeEqual，不能隐藏长度；**tokenOk(req,token)**组合两者；**unauthorized(res)**返回401 JSON，没有登录跳转。

**createHandler({dataDir,token})**返回异步handle(req,res)。先设no-store，然后在try内解析URL；`//[`等解析异常转换400/E_BAD_ARGS，而不是拒绝未捕获的listener Promise。

| 请求 | 授权 | 返回/错误 |
|---|---|---|
| GET /health | 无 | 200，仅服务健康，不读报告 |
| GET /、/index.html | Bearer | day query或UTC今天；读报告、生成HTML之后才写200 |
| GET /api/stats | Bearer | 先load/rank/序列化成功才写200，损坏存储500/E_STORE_CORRUPT |
| POST /api/report | Bearer，先验再读body | schema400、body超限413、存储错误500；成功才200 success/rec |
| 其它 | 不执行受保护操作 | 404 |

catch返回err.status或500、message及存在的code；读取/保存报告的错误已收敛为固定文案。GET日期查询仍只用于筛选/转义，不承诺统一严格query schema。所有响应no-store；没有自动分页/归档/轮换令牌端点。

**createServer(opts={})**选目录/opts.token或ensureToken，创建http.Server并返回server/handler/dataDir/token；不自行listen。

## 5. index.js入口与未验边界

读取端口默认4174、绑定默认127.0.0.1，createServer后listen；打印绑定/目录/令牌文件位置而非令牌正文。require入口也会监听，没有require.main保护；未新增完整退出协议。公网部署、TLS、限流、真实账户、备份运维仍需独立评估。

## 7. 验证

```bat
npm test -- --filter=adminHost
npm test -- --filter=adminIntegrity
npm run test:browser --prefix webagent-core/agent-host
```

adminHost保留原授权/替换/排序/body测试；adminIntegrity先用真实原生HTTP子进程复现畸形URL退出1，再要求400且health存活，另验证坏JSON/字段/容量、注入EACCES与写/rename中断、stat/open消失和零覆盖。注入错误不冒称真实Windows权限/断电测试。浏览器新增adminLayoutBrowser检查320/390/1440、字号、axe对比度/标签和键盘局部滚动；测试字体回退和真实操作系统字体分别说明。
