# publicHttps：受控公网HTTPS出站MCP

[publicHttps.js](publicHttps.js)为外部MCP客户端提供直接HTTPS POST，不开新的入站服务器。与手机Arena→本机Bridge是相反方向；开启出站不开放本机/api。

## 用户操作与信任

经典工作台Bridge→工具接入与审批：默认仍是回环模式；勾选“明确启用公网HTTPS”，填服务名称、HTTPS地址及可选Bearer令牌。登记前确认数据外发提示；提交必须publicHttps=true、confirmedPublic=true、匹配workspaceRoot/hostInstanceId。未勾选不能用公网地址，勾选不接受公网HTTP或回环地址。登记时就发initialize/initialized/tools/list，不是零网络备注，也不能保证对方收到初始化后没有内部副作用。

不把令牌放URL、查询串或片段；只允许Authorization Bearer头，注册/令牌/会话均在内存，重启重新登记。UI发送时清空令牌输入，不保存localStorage；本机列表显示端点和publicHttps标记，远端列表不含端点/令牌/会话。远端先external_request等待本机审批，Code不能越过Bridge所有者四项权限。每次实际工具调用仍单独批准，不根据第三方readOnlyHint免批。错误或unknown不自动重试，不跨服务改投。

## 地址与TLS

endpoint继续拒绝URL用户信息、query/hash和本宿主已知端口，另拒绝当前已知publicTunnelUrl的origin；localhost回环固定127.0.0.1。公网仅HTTPS；URL中的非标准IPv4先经WHATWG URL规范化，再按规范地址检查。

每次POST重新解析DNS，最多32个结果，**任一非公网结果即拒绝整个请求**，不能从混合答案里只挑一个公网地址。IPv4拒绝私网、回环、链路本地、CGNAT、文档/基准/多播/保留网段；IPv6只接受2000::/3内并排除保守的特殊/文档/6to4网段，映射IPv4、ULA、链路本地和NAT64不放行。规则保守，可能拒绝部分特殊但合法服务；不是对所有IANA未来分配的自动跟踪。

只把已检查的第一个地址交给https.request.lookup，agent=false不复用旧连接，不二次解析、不依赖HTTP_PROXY/HTTPS_PROXY环境代理；URL域名仍负责HTTP Host与TLS证书/SNI。证书验证不关闭，系统信任/机器路由属于可信环境。不能阻止可信公网服务在它自己的网络内部代理请求，也不提供OS沙箱。

禁止重定向（3xx按错误终止），因此Bearer不跟随Location跨源。同域DNS下一次若变成私网也会拒绝；不会自动选择另一个地址失败重试。Accept-Encoding=identity，不支持压缩内容的自动解压。单RPC30秒（含DNS和body），整个登记也有30秒总时限；JSON/SSE响应复用256KiB预算和ID/协议检查、分页上限。

## 逐函数

- **isPublic(address)**：net.isIP判断地址族，BlockList判断IPv4排除网段或IPv6正向范围与排除网段，非法地址false。地址语法和路由可达不是同一件事。
- **resolvePublic(hostname,signal,lookup)**：去IPv6方括号，开始/结束检查取消；IP字面量直接分类，域名dns.lookup(all/verbatim)。与取消Promise竞争；内部**abort()**拒绝等待，finally卸监听。底层系统DNS未必能强制取消，但返回的迟到结果不会再创建请求。验证全部地址与family，再返回首项。
- **post(url,{headers,body,signal},dependencies)**：复查HTTPS/URL，await resolvePublic后创建https.request，禁用连接池、保持证书验证和identity编码。对象方法**lookup(_hostname,options,callback)**只回已选地址，兼容Node的单地址/all形式；不再次解析。请求error拒绝，end发送正文；收到headers后用webBody将Node响应转换Web可读流与Headers，交externalClient.responseMessage有界读取。外层rpc的finally中止请求、清30秒计时器。dependencies只用于代码测试注入，不从用户配置/远端参数读取。

## 集成与验证

externalClient.add新增严格publicHttps/confirmedPublic和工作区绑定；rpc仅该类客户端走post，回环/stdio仍走原路径。remove中止登记和调用控制器，失败登记不保留半个目录。所有者权限/审批在执行链继续校验。

[publicHttps.test.js](../../tests/publicHttps.test.js)的**main()**检查IP段、混合DNS、非标准IP/URL、DNS取消；**lookup()**模拟DNS从公网变私网；**request()**先断言真实transport传出的固定lookup、agent=false和证书校验，再以测试专用路由把socket送到隔离本机TLS服务。真实TLS握手、Host、三段MCP发现、Bearer、批准后一次调用、重绑拒绝、307不跟随、超大响应、悬挂body取消及无测试CA的证书拒绝均被断言。该路由覆盖是测试夹具，**不是从公网实际连接成功或生产DNS端到端实证**。

fixtures/public-mcp-test-cert.pem和public-mcp-test-key.pem是公开、无生产用途的自签名测试证书/私钥（CN/SAN=mcp.example.test），仅本机隔离TLS测试使用，不在产品载荷内。不是发布签名密钥、账号凭据或可供真实服务使用的证书。

真实服务的URL、证书、OAuth流程、参数schema和兼容性仍需逐服务验收。当前只支持操作者提供Bearer，不自动OAuth发现/登录/刷新、任意自定义头、客户端证书、重定向或持久凭据；不借“HTTPS支持”保证所有远程MCP供应商兼容。

## Node18关闭/取消兼容

**webBody(response)**不用Node18的Readable.toWeb取消适配；显式terminal标志保护data/end/error/close。**start(controller)**暂停源流并绑定事件：data入队后desiredSize≤0再暂停，end只close一次，error/提前close只error一次；**pull()**恢复源流；**cancel()**先标terminal再destroy。取消后迟到data/end/error/close全部忽略，但error监听仍存在，避免未处理错误。highWaterMark=1按chunk背压，不是对socket内核缓冲的字节上限；最终读取仍有256KiB预算。
