# Skill 发现和敏感/噪声路径规则：逐函数讲解

## 职责与调用关系

[skills.js](skills.js)发现并读取SKILL.md说明，供API、Chat提示和MCP工具使用；[sensitive.js](sensitive.js)给路径工具提供敏感规则/噪声过滤。读取Skill不等于执行其中命令；隐藏噪声不等于敏感拒绝。

## 1. skills.js全部函数

### readSkillPrefix(file,chars)

先stat普通文件，再open并在try/finally中fstat；非普通或超过128KiB抛ProtocolError E_BAD_ARGS。分配最多min(stat.size,(chars+1)*4)字节，单次readSync，从UTF8文本取前chars，返回content及truncated；finally关闭fd。

按字节上限与字符窗口分别限制，不是总读全部Skill。单次read可能短读，truncated反映bytes小于原stat.size或文本超chars；不是完整文本合法性/并发变更保证。路径白名单在外部发现阶段，不在这个内部读函数。

### 发现辅助函数

| 函数 | 输入/返回 | 作用 |
|---|---|---|
| preview(file) | 路径→240字符预览/错误说明 | readSkillPrefix；E_BAD_ARGS转说明文字，其他错误继续抛 |
| skillRoots() | 无→两个目录 | `.webagent/skills`优先、`skills`其次，均在工作区 |
| bundledSkills() | 无→内置列表 | 只枚举computer-use/project-manager/multi-agent-board三个产品根目录；有SKILL.md才加入name/相对path/absDir/preview |
| skillFileFields(dir) | 目录→两个定位字段 | skillFile转正斜杠相对路径，skillFileAbs绝对路径 |
| addSkill(skills,seen,entry) | 可变数组/Set/记录→undefined | 名称已seen直接跳过，否则加入并补文件字段；修改传入容器 |

### listSkills()

按两个工作区根先后readdir遍历子目录；有SKILL.md且目录有效时，以工作区相对路径交resolveSafePath验证，失败就跳过，**用户技能不能继承内置目录例外**。成功preview/addSkill。最后遍历bundledSkills再add，按名称先到先得：工作区同名Skill可遮住内置条目。

顺序不是明确字母排序；readdir/stat/preview的一些I/O错误仍可抛出。内置技能是固定产品目录例外，不意味着用户任意绝对路径可读；relative path可带..用来描述产品外于工作区的资源。

### loadSkill({name}={})

先listSkills。无name则map返回目录定位/预览与hint；有name按find精确匹配，未知返回found:false、available名字数组及hint，而不是直接抛错。

命中后readSkillPrefix最多28000字符，返回found/name/path/absDir/skillFile/skillFileAbs/content/truncated。hint里说full也不能忽视这里的窗口；超128KiB文件仍拒绝。

名字等于computer-use则加scriptsDir和runHint，指出脚本绝对目录、截图输出到工作区、Chat视觉声明/MCP image行为。只按名字分支，不能因此证明命中的一定是内置条目（工作区可同名遮蔽）。它不会启动PowerShell、截屏或审批命令。

## 2. sensitive.js常量与全部函数

SENSITIVE_PATTERNS是内置敏感文件/目录模式；SENSITIVE_EXCEPTIONS允许.env.example/sample/template样例（只豁免env规则）。NOISE_NAMES是依赖、缓存、产物目录等，包含venv/.venv但**不是自动识别所有Conda环境路径**。

| 函数 | 输入/返回 | 行为与边界 |
|---|---|---|
| toPosix(p) | 路径→字符串 | 改分隔符、去首./，不解析真实磁盘对象 |
| globMatch(pattern,rel) | 简单模式/路径→boolean | 尾斜杠匹配目录前缀；其他转正则，星/双星有简化语义，检查整路径或basename；不是完整gitignore/minimatch实现 |
| loadCustomPatterns() | 无→模式数组 | 读根.webagentignore，split/map trim/filter去空和注释；任何异常回[]，不缓存、不限制文件字节 |
| isSensitive(relPath) | 路径→boolean | 内置规则对小写路径每层后缀匹配（map建suffixes、some匹配），env样例仅绕过相应env模式；命中内置即true。再按原路径大小写依序自定义规则：普通命中true，!命中false并立即返回 |
| isNoise(relPath) | 路径→boolean | 各路径片段some检查NOISE_NAMES，区分大小写；只关心名字，不探测真实Conda元数据 |
| isHidden(relPath) | 路径→boolean | 敏感或噪声，用于列表/搜索过滤；不等于每种直接读写都使用此联合判断 |
| assertNotSensitive(relPath) | 路径→undefined或抛错 | 命中则Error/code E_FORBIDDEN，消息给出路径；不自己校验工作区realpath |

自定义规则是**先匹配先返回**，不是Git的最后匹配覆盖语义；自定义!不能放开先前已经命中的内置保护。内置规则大小写不敏感，自定义规则不是统一小写匹配。调用方还必须把逻辑路径和真实路径都交适当检查，不能把字符串规则当整个沙箱。

Conda用户通常把环境留在仓库外；若把环境目录放到业务工作区，不能依赖`.venv`噪声名单自动隐藏它。此处只解释实际行为，不在这轮改动你的目录或扫描规则。

关注Skill允许根/读取预算、嵌套敏感路径与规则例外；不验证Skill作者内容可信性或执行命令的安全性。练习：区别“目录没显示”“路径被敏感规则拒绝”“Skill已读但没执行”三种结果，并追踪其调用方。
