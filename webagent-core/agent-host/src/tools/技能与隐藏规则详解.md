# Skill 发现和敏感/噪声路径规则：逐函数讲解

## 职责与调用关系

[skills.js](skills.js)发现并读取SKILL.md说明，供API、Chat提示和MCP工具使用；[sensitive.js](sensitive.js)给路径工具提供敏感规则/噪声过滤。读取Skill不等于执行其中命令；隐藏噪声不等于敏感拒绝。

## 1. skills.js全部函数（Skills渐进加载）

这是说明型Skill注册与读取，不是脚本执行器。固定来源依次为workspace（当前工作区`.webagent/skills`）、shared（**同一个工作区**的`skills`，不是跨项目全局目录）和bundled（三个既有产品Skill）。`id=source:目录相对路径`；保留name兼容入口，但同名时首个来源优先。所有来源均返回executable:false；来源不是授权等级。

| 函数 | 输入/返回 | 实际处理与边界 |
|---|---|---|
| boundedEntries(dir,budget) | 目录/共享预算→排序Dirent数组 | opendir逐条读取，最多remaining个，额外发现条目时标truncated，finally关闭；不是先无界readdir整目录；已收集条目按名称排序 |
| safeSkillFile(skill,resource) | Skill/相对资源→真实文件路径 | 拒绝空、超300字符、NUL、冒号、绝对路径、空/./..路径片段、敏感/噪声路径；拒绝Skill根和资源各段symlink；realpath仍须在该Skill目录内；非bundled还交resolveSafePath工作区约束 |
| readSkillText(file) | 路径→content/hash/bytes | 先拒非普通文件，O_RDONLY及平台支持时O_NOFOLLOW/O_NONBLOCK打开（避免FIFO打开阻塞），fstat普通文件且≤128KiB；固定128KiB+1缓冲循环读，检测增长超限；拒NUL及非法UTF8，SHA256针对实际读取字节；finally关闭fd。不执行文本，也不向写入哈希授权缓存登记 |
| skillDescription(text) | 正文→最多240字符 | 前4000字符内读取显示用frontmatter：description普通单行及简单竖线/大于号折叠块；不执行或完整解释YAML；无描述时取正文首个非标题/代码围栏行；frontmatter name不能改真实目录ID |
| describeSkill(source,name,absDir) | 来源/名称/目录→描述项 | 生成id/path/skillFile/skillFileAbs、kind=instructions、executable=false；读取240字符preview及description，失败仍显示ready:false与原因 |
| discoverSkills() | 无→skills/truncated/warnings | 内部walk递归最多3层；只识别有普通SKILL.md的目录，发现后不将其资源再当Skill；跳过symlink/隐藏/噪声。两个工作区根共享512目录条目预算、最多128项，再加固定3个bundled；最多20条异常提示。按来源优先级设置shadowed，同名项不删除 |
| listSkills() | 无→数组 | discoverSkills().skills兼容原消费者，不做mtime缓存；完整扫描元信息需discoverSkills |
| skillResources(skill) | Skill→resources/resourcesTruncated | 内部walk最多3层资源目录、200条目、20项；同样做真实路径/敏感检查，跳过符号链接。按后缀/大小标记是否可请求文本，不代表内容已通过UTF8检查。脚本只读源码，二进制不送文本工具 |
| integer(value,fallback,max,label,min) | 参数→整数或E_BAD_ARGS | 严格Number.isInteger与上下界；不把字符串当合法MCP整数 |
| loadSkill(args) | 参数→目录页、正文页或found:false | 无name时cursor/pageSize默认20（最大50），返回nextCursor和scanTruncated；有name先匹配id，再按name兼容查找，不递归猜basename。resource默认SKILL.md，offset默认0，limit默认/最大8000 UTF16字符；单资源≤128KiB。offset>0必须带expectedHash，版本不同报E_STALE_FILE，从0重新读；nextOffset=null表示到末尾。第一页SKILL.md带有限资源目录；脚本只读、加载不安装依赖。 |

分页hash是本次字节快照，不是已批准执行或永久缓存标识。`offset`是JS字符串UTF16索引，不是文件字节/行号；用返回的nextOffset续读。工具预算器识别offset，不二次剪断页正文；目录变化后可重新列，目录分页不是跨变更事务快照。边界检查不承诺抵御具有并发修改宿主文件系统能力的攻击者的所有竞态。

只有`source=bundled`且name=computer-use且读取SKILL.md时，附加既有scriptsDir/runHint；工作区同名项不再继承产品脚本提示。加载这些说明仍不会运行PowerShell、截图、键鼠或审批。

## 2. sensitive.js常量与全部函数

SENSITIVE_PATTERNS是内置敏感文件/目录模式；SENSITIVE_EXCEPTIONS允许.env.example/sample/template样例（只豁免env规则）。NOISE_NAMES是依赖、缓存、产物目录等，包含venv/.venv但**不是自动识别所有Conda环境路径**。

| 函数 | 输入/返回 | 行为与边界 |
|---|---|---|
| toPosix(p) | 路径→字符串 | 改分隔符、去首./，不解析真实磁盘对象 |
| globMatch(pattern,rel) | 简单模式/路径→boolean | 尾斜杠匹配目录前缀；其他转正则，星/双星有简化语义，检查整路径或basename；不是完整gitignore/minimatch实现 |
| loadCustomPatterns() | 无→模式数组 | 读根.webagentignore，split/map trim/filter去空和注释；任何异常回[]，不缓存、不限制文件字节 |
| isSensitive(relPath) | 路径→boolean | 内置规则对小写路径每层后缀匹配（map建suffixes、some匹配），env样例仅绕过相应env模式；命中内置即true。再按原路径大小写依序自定义规则：普通命中true，!命中false并立即返回 |
| isNoise(relPath) | 路径→boolean | 各路径片段some检查NOISE_NAMES，区分大小写；只关心名字，不探测真实Conda元数据 |
| isHidden(relPath) | 路径→boolean | 敏感或噪声，用于列表/搜索过滤；不等于每种直接读写都使用此联合判断 |
| assertNotSensitive(relPath) | 路径→undefined或抛错 | 命中则Error/code E_FORBIDDEN，消息给出路径；不自己校验工作区realpath |

自定义规则是**先匹配先返回**，不是Git的最后匹配覆盖语义；自定义!不能放开先前已经命中的内置保护。内置规则大小写不敏感，自定义规则不是统一小写匹配。调用方还必须把逻辑路径和真实路径都交适当检查，不能把字符串规则当整个沙箱。

Conda用户通常把环境留在仓库外；若把环境目录放到业务工作区，不能依赖`.venv`噪声名单自动隐藏它。此处只解释实际行为，不在这轮改动你的目录或扫描规则。
