# 任务板、Git 与工作区聚合：逐函数讲解

## 职责

[board.js](board.js)保存任务元数据，[gitOps.js](gitOps.js)封装只读Git，[workspaceInfo.js](workspaceInfo.js)聚合进入工作区时的概览。任务板不是共享对话/凭据仓库，也不会替用户认领后自动写代码。

## 1. board.js基础函数

| 函数 | 参数/返回 | 状态与边界 |
|---|---|---|
| serial(fn) | 回调→Promise | chain.then排队，另接成功/失败空回调修复尾链，使一次失败不阻塞后续；只串行本进程 |
| boardPath() | 无→路径 | workspaceRoot/.webagent/board.json，未复用通用路径沙箱 |
| loadBoard() | 无→{tasks} | readBoundedText限额读取普通UTF-8文件，JSON有tasks数组才接受；仅ENOENT退空板，其他读/解析/缺tasks数组抛E_BOARD_CORRUPT，避免坏板被新任务覆盖；无完整任务schema |
| saveBoard(board) | 对象→undefined | 建目录、随机.tmp.临时名、wx/0600写入、rename，finally清理；无跨进程锁，不等于断电事务 |
| callerOf(ctx) | 上下文→字符串 | ctx.callerKey或local；网络入口应提供认证后的peer上下文 |
| stamp() | 无→ISO时间 | 当前时间，不按任务单独计时器 |
| nextId(board) | 板→tN | 查现存id最大数字+1，不是UUID；手工删最高项可能重用ID |
| view(task) | 记录→显示对象 | 精选身份/时间/状态，notes只最后5条；不深拷贝每条note |

**peersList(_args={},_ctx={})**从allSessions.map出client/key/计数/时间，10分钟内alive；不同于状态页10秒alive窗口。已初始化会话的key为`peer:`随机标签；无会话调用者的key为client@ip加凭据派生的盐化标签（F71，见会话与结果详解sessionKey），同样不暴露凭据，但不能当作按对话区分的正式身份。

**boardList(_args={},_ctx={})**load，filter统计open，map(view)返回任务；读取不走serial，不负责清理坏数据或分页，总任务数没有该文件内硬上限。

**boardCreate(args={},ctx={})**标题trim截200，空返回业务E_BAD_ARGS；合法在serial闭包里load/new id，初始open/owner null/createdBy，note截500，append/save，返回view。未持久化前发生错误Promise拒绝；已有坏板会从load抛E_BOARD_CORRUPT，不以空板继续保存；这是原文保留而非自动修复。

**boardClaim(args={},ctx={})**空id业务失败；队列内find，找不到E_NOT_FOUND，非open E_TAKEN。args.owner若提供必须等于caller，不能覆盖成别的peer。设置owner/claimed/时间再save。两次同进程并发认领只能一项看到open，但不保证跨进程协调。

**boardUpdate(args={},ctx={})**先验证id、status枚举、至少status/note之一，再serial查任务。改状态必须已认领且caller=owner；allowed转移表：claimed→doing/done/failed/open，doing→done/failed/open，done或failed→open；同状态可保留。释放到open清owner/claimedAt。任何peer可只加note，最多保留50条、view只5条。更新时间、save并返回；错误是业务ok:false，并非全部抛异常。

BOARD_REL/PEER_ALIVE_MS为导出常量，_boardPath/_serial是同函数别名，_rand直接暴露crypto.randomBytes供内部/测试，不是另一个任务ID函数。重启授权与板文件生命周期不同：板保留，peer可能需要重新认领安排，不会自动迁移旧owner到新身份。

## 2. gitOps.js全部函数

**notGitResult(extra={})**构建ok:true但available/git=false、空files/branch/summary及提示的对象，再extra覆盖；表示普通文件工具仍可用，不自动git init。

**git(args,timeoutMs=8000)**固定cwd、UTF8、512KiB maxBuffer。先用git config --null --name-only --get-regexp只读取filter驱动配置键名（不返回值、不启动驱动）；匹配的每个driver临时覆盖clean/smudge/process为空、required=false，再执行status/diff。无匹配退出1正常继续，其它发现错误不运行正文命令。两个同步子进程共享剩余约8秒预算；缺Git/非仓转GIT_UNAVAILABLE，其它错误仍E_INTERNAL，不能称所有超时都E_TIMEOUT。

全局--no-optional-locks避免可选索引刷新锁，--literal-pathspecs防用户filePath被当Git glob/pathspec，core.fsmonitor=false禁用监视辅助程序；diff另禁--ext-diff/textconv。覆盖仅对本次Git调用，不改仓库配置。Git内建文本规范化仍可能存在；禁自定义filter后diff/status可能与默认终端结果不同，LFS等大文件也可能触发预算拒绝。这不是OS沙箱或对恶意Git二进制/并发改配置进程的隔离。

**workspacePrefix()**执行`git rev-parse --show-prefix`并去掉行尾换行，得到工作区根相对仓库根的POSIX前缀。工作区根就是仓库根时返回空串，本函数及所有基于它的换算都是恒等操作；工作区根位于更大checkout的子目录时返回形如`sub/`的前缀。这是路径投影，不是权限检查。

**stripPrefix(prefix,repoPath)**把Git给出的仓库相对路径转成工作区相对路径：空前缀原样返回；有前缀且命中则去掉前缀；不以该前缀开头（即位于工作区之外）返回null，由调用方丢弃该条目。它只做字符串换算，不解析真实磁盘对象，也不替代resolveSafePath。

**diffPathspecs(prefix,staged)**先用`diff -M --name-status -z`（staged时加--cached）枚举本次差异涉及的路径，R/C记录消费旧/新两侧。逐条stripPrefix后对**每个**路径调用isSensitive：命中的进excluded并被排除，其余进allowed。返回的是工作区相对pathspec列表，供下一次真正的diff作显式白名单；它不读取文件正文，也不是通用秘密扫描器。

**gitStatus()**先取workspacePrefix，再用porcelain v1 -z -b并追加`-- .`把结果限制在工作区子树，NUL分记录，不按路径内换行拆行、不需要反解Git的引号转义。首条summary解析普通/无提交分支前缀，release/1.2.3保留完整，detached为HEAD。后续条目前2字符为code，第3字符以后为目标path；R/C另外消费一个原路径记录返回originalPath；两侧都经stripPrefix，越界条目直接丢弃（`-- .`已排除，这是第二道防御）。只返回前80项，实际超过80才truncated；不是恰好80就截断。JS按UTF-8解码，任意非UTF-8文件名字节不保证可逆。GIT_UNAVAILABLE返回notGitResult，其余抛出。

**gitDiff({filePath,staged=false,stat=false}={})**cached/stat选项后加--；工作区根是子目录时另加--relative，使输出路径同样是工作区相对的（根即仓库根时该选项无效果）。

- **指定filePath**：先resolveSafePath（其中已包含敏感规则与越界拒绝），再传字面相对路径，`*.txt`不匹配所有txt文件。
- **未指定filePath**：不再执行"整仓diff"。先由diffPathspecs枚举并过滤，再把allowed作为显式pathspec传给真正的diff。因此**默认diff与显式单文件diff受同一套逐路径敏感规则约束**：曾被跟踪、后来加入.gitignore的`.env`一类文件不会再经由"整体差异"回流。被排除的路径以`excludedSensitivePaths`列出（只有路径名，没有正文）。allowed为空时直接返回空diff，不启动第二次Git。
- pathspec上限MAX_DIFF_PATHSPECS=300；超出时截断并置`truncated:true`与`pathspecLimit`，不静默丢弃。

输出stat前80行，否则200行，附totalLines/truncated。Git不可用正常返回available:false，不自动git init。仍须明确：这是逐路径规则的一致化，**不是通用脱敏器**——敏感规则没有覆盖的文件里如果写了密钥，diff照样会返回；`run_command`一类命令也不经过本函数。

## 3. workspaceInfo()

唯一导出，无参，返回root/identity（hostIdentity）/packageName/git简表/environment/techStack/skills/topLevel/rules/hint。按顺序loadCustom、resolve环境/技术栈；gitStatus失败catch成available:false；listDir非递归深度1并map name/type/path，失败空列表；根package.json解析失败packageName=null；技能map名称，再getInstructions。

并非所有依赖都catch：定制、技能或规则读取仍可能抛错。路径/包名是本机信息，规则可能含用户自定义内容；不是完全匿名化资源。列表/环境结果是启发式，没有启动模型或运行测试。
