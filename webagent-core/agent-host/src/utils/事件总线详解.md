# eventBus.js：事件、日志、WebSocket 与脱敏副本

## 职责、对象和流程

[eventBus.js](eventBus.js)定义BridgeEventBus并导出一个实例，另挂sanitizePayload供测试/调用。事件同时走两个通道：**WS/日志的脱敏副本**，以及**进程内EventEmitter原始payload**。两者保证不同，不能说“进入总线就全部脱敏”。

```text
broadcast(type,payload)
 → sanitizePayload → 日志最近500条 → JSON → 就绪WS客户端
 → this.emit(type,原payload) → 内部同步订阅者
```

## 1. clipStr(s,max=4000)

String转换，超max先截前段加省略号，再用SECRET_RE替换常见PAT/API Key/Bearer形式为redacted。不是识别所有秘密的通用扫描器；先截后匹配可能使跨截断位置的模式不再完整。不要因为用过它就主动把凭据写进事件。

## 2. sanitizePayload(value,depth=0)

nullish原样；字符串clipStr；数字/布尔原样。其他类型到深度6返回省略标记；数组取前40，map递归。对象只取前40个键，SECRET_KEYS命中直接redacted，CLIP_KEYS（diff/patch/content/chunk/stdout/stderr/args/body/command等）且值为字符串时先限500，再递归；其他类型String后限200。

这是展示摘要，会丢数组成员/对象键，**不同于MCP预算保留结构**；不适合拿摘要还原业务数据。SECRET_KEYS是精确命名集合，不是任何“含token”字段都识别。深度限制能终止常见循环对象递归，但读取getter/键等仍可能抛错，并非永不失败。

## 3. BridgeEventBus 的所有方法与回调

### constructor()

super建立EventEmitter；wsClients Set、idleTimers WeakMap、logs数组，maxLogs=500。创建实例不监听TCP，真正WS入口在src/index.js。

### _clearIdle(ws)

从WeakMap取timer，存在就clearTimeout并删除映射。只清该客户端的计时器，不关闭socket。

### _touchIdle(ws)

先_clearIdle，再建立30分钟timeout；回调尝试ws.close(1001,'idle')，关闭异常吞掉；支持时unref，再保存timer。这里的活动是在后续broadcast成功发送时刷新，不是任何浏览器键盘动作或网络ping都刷新。

### addWsClient(ws)

Set已32个就尝试close(1013,'too many sockets')并返回false。否则加入，设idle，注册close匿名回调负责清timer、从Set删除，返回true。没有在此验证来源/身份，那是在握手/入口中完成。

同一对象重复注册可能再加close监听，容量也没有对重复调用特别分支；当前入口应每次连接注册一次。关闭事件未触发前仍可占Set项，不是仅按readyState即时回收。

### broadcast(type,payload={})

生成含type/ISO时间/脱敏payload的eventObj，logs.unshift，新长度超maxLogs就pop。JSON.stringify一次后遍历wsClients，只给readyState===1发；try中send后_touchIdle，异常吞掉，不自动从Set移除。

最后this.emit(type,payload)传**原对象**给内部订阅者。EventEmitter监听同步执行，监听器抛错可使broadcast抛错；此前日志/WS可能已发送，不是全通道原子事务。内部监听器也可能修改原对象，调用者不能将其当不可变消息。没有按ws.bufferedAmount做积压闸门，客户端数量有界不等于所有慢客户端缓冲都已严格有界。

### getRecentLogs(limit=50)

返回logs.slice(0,limit)，新到旧；数组是浅拷贝，事件对象仍共享。没有对limit单独做数值范围验证；API调用者需约束展示参数。

## 4. 验证与复盘

```bat
npm test --prefix webagent-core/agent-host -- --filter=eventBus
npm test --prefix webagent-core/agent-host -- --filter=resourceBudget
```

检查脱敏/裁剪/容量相关断言，真实浏览器断线重连和长挂仍看人工清单B3/B4。复盘时分别画出raw payload与sanitized副本，解释为什么get_logs中的内容可能不全，以及为什么它不适合作为补丁原文恢复来源。
