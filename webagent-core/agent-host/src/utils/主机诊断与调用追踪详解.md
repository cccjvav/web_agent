# 主机诊断、任务上下文和读回核验

## hostDiagnostics.js

- **hostIdentity()**从config取本次进程的hostInstanceId、startedAt、工作区、版本和两端口。UUID在进程启动生成，不持久化，不等于installId或访问密钥；status、ping、workspace_info、initialize元数据、Bridge快照共用。
- **findExecutable(name)**按PATH和Windows扩展名候选做stat/access，只返回发现的路径，不执行候选程序。找到解释器不等于已验证运行，更不是安装或提权授权。
- **diagnostics()**只检查目录读写权限、PTY匹配心跳及Windows PowerShell候选。返回ready/unverified/unavailable及原因；写权限只初检，不能充当真实写文件验收。不会启动命令、截图、安装或创建探针文件。GET /api/diagnostics与其他API共用本机边界；get_capabilities给认证MCP同一能力表。

## toolTrace.js

- **withTask(info,fn)**用AsyncLocalStorage为本次Chat/工作流保持任务上下文，缺taskId生成UUID；不是权限上下文。
- **sessionIdFor(options={})**把callerKey用本进程ID盐化SHA256后截断为会话标识，不保存令牌/原sessionKey；get_logs也复用它过滤远程调用者自己的执行记录。
- **taskId(value)**只接受受限t编号或UUID形状，否则新建UUID。可把MCP `_meta["webagent/taskId"]`设为任务板ID来关联，但关联不等于认领权或任务完成。
- **beginCall(tool,options)**限制最多64个running调用，生成callId并调用sessionIdFor。source区分Bridge-Remote、Chat、Local等受控调用来源。保留至多200条（新建时清旧完成项），不驱逐活动项；发tool_execution_start。
- **finishCall(record,result,error)**更新结束时间、耗时、execId及成功/失败/取消/accepted/unknown状态，记录核验状态；错误只存受限错误码，不存错误正文、命令、参数或文件内容。命令仍运行时标accepted，不把已提交命令当完成任务。发tool_execution_end，返回副本。
- **snapshot(source)**按来源过滤并复制记录，最新在前；**clearCompleted()**清已完成项但保留running。主机重启会丢历史，清轮不取消在途操作。
- **verifyMutation(tool,input,result)**对write_file/apply_patch读取磁盘并对比hash/newHash；delete_file验证不存在，rename_file验证源消失且目标存在。dryRun不核验写入。失败返回success/ok=false和verification=unknown，明确可能已经写入，不能自动重放。只证明核验时刻的条件，不保证随后无人修改、目录内容事务或业务目标已完成。

## 工具入口与前端

callTool包围原分发逻辑dispatchTool；权限/危险命令/路径校验仍在dispatchTool，追踪不能绕过它。未知工具记录为unknown-tool，不把任意输入当日志名称。结果带trace；异常带err.trace供MCP响应_meta关联。Bridge快照含执行记录，可在RPC尚未完成时显示running；完成计数仍按MCP完成事件，不能把数量当任务成功证据。

## isToolFailure(result)：传输层共享业务失败判定

输入工具返回对象，输出boolean。显式ok/success=false、isError、isTimeout、非零exitCode、失败/取消/unknown状态、trace失败/取消/unknown及verification未知均判失败；available:false不等于执行失败，running/等待审批也不当作已完成。API外包success和MCP isError共用该函数；原始result保留，不因归一而删掉错误详情。无对象返回false，不代表对任意返回schema进行了认证。
