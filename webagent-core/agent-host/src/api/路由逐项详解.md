# routes.js：本机 API 的每个路由与回调

## 职责、前置条件与数据流

[routes.js](routes.js)导出Express router，由入口挂在`/api`并先做本机控制面/跨站检查；本文件不是独立对外认证服务。以下路径省略`/api`。依赖模型/工具/配置/隧道/PTY/事件模块，路由主要负责取参、调服务与映射响应。

不要假设所有错误格式一致：有些路由自己try/catch，有些依赖Express错误处理中间件；大多数JSON成功外壳不能取代业务判定。默认JSON body上限由入口设置，本文件导入MAX_TEXT_BYTES并用于本批文件正文类型预算，但没有把固定包装辅助器接成router全局schema。

## 3. 文件与技能路由

**GET /files/tree**：query必须为空，未知键固定400且不会调用list_directory；合法请求以ask模式列根目录、递归深度5，结果直接json，抛错400。UI文件树不是完整磁盘清单。

**GET /files/content**：query只能含path，且path为非空、单行、≤4096 UTF-8字节字符串；不再以String强制转换数组/对象。随后resolveSafePath检查路径与敏感文件；不存在或目录404；readBoundedText读普通文本，computeHash、rememberHash，再返回path/content/hash/size。size是JS字符串length，不是文件字节数；合法读会更新哈希缓存，不能说绝无状态副作用。其它异常400。

**PUT /files/content**：顶层只允许path/content/expectedHash/createOnly，未知字段或错类型在capture/callTool前固定400/E_BAD_API_REQUEST。path须非空单行≤4096字节，content≤MAX_TEXT_BYTES。新建必须显式`createOnly:true`且不得混带hash；只有该分支不捕获回退，向write_file传createOnly:true/confirm_overwrite:false。其它保存（createOnly缺省或false）必须提供64位小写expectedHash，再以confirm_overwrite:true进入版本化覆盖；省略hash不再能创建或盲目覆盖，字符串`"true"`也不会退入普通保存。成功返回path/hash/verification/undo；E_FILE_EXISTS/E_STALE_FILE映射409，其他工具异常400。独占发布和实际hash复查仍由工具层完成，路由没有直接fs.writeFile；固定包装不消除外部OS竞争或写后unknown。

**检查点路由**：GET `/checkpoints`只收空query。创建body只允许paths/confirmed/工作区/主机，preview与remove只允许绑定，restore另允许previewId/confirmed；未知字段在fileCheckpoints调用前固定400/E_BAD_API_REQUEST，因此不会分配记录、生成/消费ticket、写文件或删除记录。合法输入的严格确认、路径/总量、绑定、hash、一次消费及部分失败仍由fileCheckpoints负责；路由固定包装不把多文件恢复变成原子事务。

**GET /skills 与 /skills/load**：目录GET只接受空query。load只允许name/resource/expectedHash/offset/limit/cursor/pageSize；字符串、hash和十进制数字文本在callTool前校验，未知/对象/数组型query固定400。合法discoverSkills返回skills/truncated/warnings，保留source/id/description/ready/shadowed及路径，向本机编辑器提供定位；包含绝对路径，不是完全匿名化资源。

**POST /skills**：body只允许name/content；name须为≤256字节单行非空字符串，content存在时须字符串且≤MAX_TEXT_BYTES，未知/错类型在写前固定400。随后name trim、非ASCII word/连字符替换为`-`、去首尾横线、截40，空则400；content假值仍用默认模板。写`.webagent/skills/<name>/SKILL.md`，内部createOnly:true、code模式；写路径锁内拒绝已有同名文件。只有callTool返回success严格true且read-back verification为verified才返回成功目录；返回式失败/unknown映射409并保留code/verification，提示核对目标。名字正规化可造成不同输入落同名，UI不能假设中文名原样保存，也不是自动安装扩展代码。

## 4. 工具、共识与 Chat 流

**POST /consensus/run**：顶层只接受taskDescription，且须为非空白、≤1MiB字符串；未知/错类型在control.run及事件副作用前400/E_BAD_API_REQUEST。合法值交runMultiModelConsensus，success/result；执行异常500。路由不再接受并忽略modelConfigs等伪参数；实际导出的共识入口应继续读tools/index及consensusEngine，不能只凭路由名推断一定调用多个外部模型。

**POST /tool/call**：包装只接受name/arguments/mode。name须为≤128字节的小写工具标识，arguments缺省`{}`但存在时必须为非数组对象，mode缺省code且只允许ask/plan/code；未知字段在start广播和control.run前400/E_BAD_API_REQUEST。合法请求发start、await callTool，再由共享isToolFailure计算success，完成事件与JSON外壳使用同一值。HTTP200保留返回的result（包括错误细节），不把结果式失败当成功；抛错仍400。固定外包装不替代每个工具的inputSchema、模式权限或审批。running/等待审批是已受理，不等于已完成。

### POST /chat 的全部闭包与结束顺序

1. 先用固定顶层字段表拒绝未知包装，再由validChatRequest核对mode/think/action组合、消息/模型ID预算、最多12条且角色/字段固定的1MiB历史，以及extension绑定字段。失败固定JSON 400/E_BAD_API_REQUEST，发生在流头、AbortController、PTY、模型和工具之前；扩展结构通过后仍由assertWorkspaceBinding作409实际绑定判断。
2. 新建AbortController；**abort()**调用controller.abort；5分钟timeout调用abort。
3. **disconnected()**在res尚未writableEnded时abort；注册req aborted与res close。
4. 设置NDJSON/no-cache/no-transform/X-Accel-Buffering，能flushHeaders则立即发头。此后的错误通常已不能改HTTP状态。
5. **emit(type,data={})**仅在未destroyed/未结束时写一行JSON+换行，类型与data合并；不检测write背压，也不提供逐token模型流保证。
6. body.client严格等于vscode-extension才pty=true；runWithSignal闭包套runWithPty({pty,remote:false,emit})异步闭包，再runChat传mode/message/history/modelId/thinkLevel/planAction/emit。这里直接传mode，没有把agent改code。非扩展client值及其夹带绑定会在第1步拒绝。
7. await正常结束发done；抛错发error。**runChat内部可能已emit error然后返回失败对象，路由仍发done**；done是流处理结束不是业务成功。
8. 清timeout，off两个监听；未destroyed则res.end。

Ask/Code及Plan start要求非空白message，Plan branch/merge/reset可空；message最多1MiB，单条history content最多256KiB且总计1MiB。thinkLevel仅low/medium/high，planAction仅start/branch/merge/reset且只准Plan。该包装预算不是Token计数，也不限制模型生成请求里的图片等独立数据。

取消只传到实际接入的下层，已经完成的写入不回滚。清理代码在try/catch之后而非finally，若错误emit自身再抛，不保证走完末尾清理；不要把它说成任意异常下都已形式化保证。

## 6. Bridge 生命周期及其身份路由

### POST /bridge/start

先把缺body视为空对象，再要求顶层只能有workspaceRoot/hostInstanceId/tunnelProvider及Named/ngrok各自domain/Token。绑定字段、域名和Token分别有4096/256、512、4096 UTF-8字节预算并拒绝CR/LF/NUL；provider只接受cloudflare、cloudflare-named/named、ngrok或无公网进程的local。Named字段不能塞进Quick/ngrok，ngrok字段不能塞进其它provider。任一失败固定400/E_BAD_BRIDGE_REQUEST，错误不回显输入，且发生在配置写入、旧隧道停止和提供商触网前。

随后核对工作区绑定并读配置；历史非法provider只作cloudflare缺省，历史domain/Token仅字符串才可能复用，且当前provider实际会用到的保存值仍须通过同一字节与控制字符预算，否则同样在副作用前400。loggedIn/deviceAuthorized必须严格为布尔true，truthy对象/字符串不能授权启动。全局bridgeGeneration在取得执行租约后才+1并捕获ticket；域名允许显式空清除，Token只有本次非空才覆盖旧保存值，因此空Token不是“清除凭据”。store.patch发生在实际停启前。

将运行状态置false、公网URL置null、设provider、ensurePairing。await tunnel.stopTunnel（它包含ngrok停止），失败记tunnelError；await后ticket过期返回409。无停止错误才按Quick/Named/ngrok分支启动，异常记录而非抛成功；local不启动公网进程。

启动后再核对ticket，过期409；仅无tunnelError且config.publicTunnelUrl有值时bridgeRunning=true，发started/failed，返回success/running/provider/note/error+mcpInfo。可能HTTP200但success=false。日志得URL仍不是从手机到本机的端到端证明。启动前已经保存的provider/token不会因连接失败自动回滚。

### 其他生命周期路由

| 方法/路径 | 执行顺序 | 不应误解 |
|---|---|---|
| POST /bridge/stop | 包装只接受workspaceRoot/hostInstanceId；有任一字段先要求完整绑定，否则409，完全空体保留旧兼容；未知/错类型/超预算400。然后generation++，await stopTunnel，运行false，广播，返回success:true/running:false+mcpInfo | 包装/绑定拒绝不改generation/隧道。停止抛错不发布停止；广播抛错可能HTTP500但已停止。既有generation拒已受理启动的迟到完成，不保证撤回尚未到达服务器的启动；不撤销全部OAuth或自动取消工具任务 |
| POST /bridge/reset-secret | 包装只接受workspaceRoot/hostInstanceId/expectedSecret；generateNewSecret，oauth.revokeAll，广播rotated，返回mcpInfo | 携任一绑定/CAS字段就要求完整绑定及旧密钥匹配，否则409且不写入/撤销；**只有完全空体**保留旧兼容，未知字段不能借旧路径触发轮换。比较与generateNewSecret在单进程同步段，先保存再发布内存；保存失败不撤销OAuth，写后广播失败可能500但已轮换，旧expectedSecret再提交409。非跨进程事务或永久去重 |
| POST /bridge/reset-round | 只接受空体；mcpReset，resetHashes，广播，返回空session | 未知字段400且不重置；成功也不清Plan回合、用量、记忆、任务板，不停止所有进程 |
| POST /bridge/login | 只接受空体；github.clearGithubKeepDemo后返回local-demo确认 | 本机演示标记，不是GitHub登录；同时淘汰旧设备码/PAT身份结果，避免迟到请求覆盖 |
| POST /bridge/token | 包装只接受token；存在时须字符串、≤4096 UTF-8字节且无CR/LF/NUL，再github.loginWithToken | 未知/错类型/超限在触网前固定400且不回显Token；缺失/空Token仍由身份模块给用户可读400，成功对象不含原Token |
| POST /bridge/device | 只接受空体→github.startDeviceLogin | 未知字段在触网前400；成功为success+码/授权地址，错误状态及code |
| POST /bridge/device/poll | 只接受空体→github.pollDeviceLogin | pending/done对象，不强加success；异常按status或400 |
| POST /bridge/github/clear | 只接受空体→clearGithubKeepDemo | 回演示身份，不代表停隧道 |
| POST /bridge/logout | 只接受空体；generation++，resetPending，store写未授权，await stopTunnel，运行false | 未知字段不改变身份/隧道；成功不调用oauth.revokeAll；若停止失败，身份可能已先改变，不是全事务 |

## Bridge活动快照补充
GET `/api/bridge/activity`只调用eventBus.getBridgeActivity，不执行工具；受与其他/api相同的loopback、Host、Origin及隧道头拒绝保护，不增加公网例外。返回本进程epoch/revision、累计stats和最近100条完成摘要。POST bridge/reset-round原有广播会同时清此快照，读缓存/会话原重置语义保持。

## 只读诊断与核验
GET /api/diagnostics返回hostIdentity及只读能力探测，不能安装/写入/操作桌面。GET status增加identity。文件PUT在写后核验失败时返回409/E_VERIFY_UNKNOWN，不返回假的保存成功；成功含verification。


## 本机受控执行路由

`operationApi`仍为external/workflows等若干端点统一异步JSON响应及400错误；operations列表/详情/批准/取消现在先各自固定REST包装：GET只接受空query，approve body只允许confirm，cancel body必须为空。未知字段在operatorQueue.approve/cancel前固定400，不能执行或撤销待批任务。合法批准仍要求confirm严格true；返回HTTP200只表示路由取得队列状态，不代表任务succeeded，须读取status与详情result。非终态handler报告和写后异常保守unknown，取消意图保留为cancelRequested；终态从finishedAt完整保留15分钟，迟到cancel不能把expired改写为denied。完整输入结果仅本机或原提交会话可读。workflows的preview/request连同各自包装字段共享严格顶层/步骤/条件schema，只允许安全前序步骤引用，未知/矛盾合同在进入审批前失败。详见[受控工具与工作流详解](../utils/受控工具与工作流详解.md)。

## Skill目录与分页查看
GET `/api/skills`返回discoverSkills的skills、truncated、warnings，新增source/id/description/ready/shadowed，不再丢弃来源。GET `/api/skills/load`将查询中的offset/limit/cursor/pageSize转换为数字后通过统一callTool(load_skill,args,ask)只读调用；未知404、版本变化409、其他错误400。原本机Host/Origin/隧道拒绝边界不变，无第三方安装或执行入口。

### stdio启动路由
POST /external/stdio/preview只做本机启动配置与文件hash审阅；POST /external/stdio/start消费2分钟一次性previewId且confirmed必须true。启动会执行第三方代码，所以不是只读工具目录路由。两者仍在rejectUnlessLocalControl/rejectCrossSiteApi之后，远程MCP不提供启动入口。

本机连接核对API：POST /connection-checks接收最小页面摘要并创建挑战；GET /connection-checks/:id读到期前元数据/收据；DELETE /connection-checks清空内存核对。operationApi统一错误，沿用本机与Origin边界；不存在本机直接确认路由，确认必须经认证且初始化的MCP工具。


工作区绑定（0.7.1）：POST /bridge/start必须携带workspaceRoot与hostInstanceId；POST /chat的vscode-extension客户端同样要求。前置assertWorkspaceBinding拒绝409，不先修改bridgeGeneration、授权或启动隧道。现有本机控制边界未取消；绑定不声称能远程证明IDE真实状态。验证见workspaceEntry/bridgeTunnel。


0.7.2 status.taskState仅本地Chat；status.bridgeTaskStates为按远程会话隔离的报告，activity.taskStates同源。recentToolLogs改读主机独立Bridge活动摘要，不从混合WS日志中筛选，防止桌面Bridge把本地工具混显示。tasks/reset仍只重置报告，不取消执行。验证taskProgress/真实浏览器任务上报。

## 所有者执行控制

GET /execution-control只接受空query再回读模式/请求计数/权限/revision；POST顶层只允许workspaceRoot/hostInstanceId/permissions/workMode/revision，未知字段固定400且不改变模式/策略。合法POST要求工作区/主机绑定，workMode与permissions不同时修改；权限须当前revision和四个布尔值，冲突/忙返回409，不自动取消。status增加executionControl。Bridge/start在隧道await前预占Bridge，并在finally释放；在途任务拒绝隐式重启。/tool/call、consensus包裹Chat租约；/chat经runChat获得租约。人工编辑器文件接口不是模型Chat运行，不因Bridge禁掉操作者编辑。验证见executionControl及apiFiles真实HTTP夹具。

## POST /files/preview：编辑器已有文件草稿

顶层只允许path/content/expectedHash；未知字段、非字符串、非单行/超4096字节path或非64位hash固定400/E_BAD_API_REQUEST，并在resolve/diff前结束。安全路径后读取当前普通文件并核对hash；已删除/漂移409，不创建文件。每份文本64KiB/2000行；diff库timeout=100ms、maxEditLength=4000，结果超过256KiB或预算耗尽413；读取异常400。返回success/path/expectedHash/newHash/diff，不调用写工具、不更新readCache、不发写入事件。预算是本机同步计算限制，不是独立Worker硬实时保证。PUT保存继续校验同一hash；预览不是锁或事务。验证apiFiles与实际浏览器流程。

## 受保护编辑回退接口

PUT /files/content在版本化普通保存前capture，验证成功后remember；独占新建不分配记录，可选undo分配异常不把成功保存改报失败。响应undo={id,expiresAt}或null。GET /files/undo/:id只接受空query再生成只读diff。POST同路径顶层仅允许confirmed/expectedHash/workspaceRoot/hostInstanceId，要求confirmed严格true、64位hash及有界完整绑定；未知/错类型固定400且不消费记录，结构通过后assertWorkspaceBinding或restore冲突仍409。细节/边界见utils/编辑回退详解：仅本机手动编辑，不是远端MCP新权限，也不是全操作事务。

/external/servers登记公网时要求publicHttps/confirmedPublic严格布尔确认及workspaceRoot/hostInstanceId；实际外发由publicHttps逐请求验证DNS并固定连接。默认仍回环；不新开远端管理API，Bearer不持久化。
