# config.js 与 extensionVersion.js：运行配置、身份和版本

## 职责与初始化流程

[config.js](config.js) 导出一个进程内共享可变config对象和两个身份函数；[extensionVersion.js](extensionVersion.js)读取产品版本。config在首次require时计算，而不是每个请求重新读取所有环境变量。测试可修改config.workspaceRoot，因此依赖它的读写函数常在调用时算路径。

| 字段 | 来源/默认 | 使用与边界 |
|---|---|---|
| workspaceRoot | WORKSPACE_ROOT或源码仓库根目录，path.resolve | 相对路径按启动cwd；这里只算路径，不验证目录存在 |
| port/workbenchPort | AGENT_HOST_PORT=48271 / WORKBENCH_PORT=3000，parseInt | 字符串解析不是完整端口范围校验；非法值可能在监听时才失败 |
| host | WEBAGENT_BIND或127.0.0.1 | 默认本机；不因为开远程MCP就必须将UI公开 |
| secretKey | 初始随机12字节hex | 启动后可能被persistIdentity替换为落盘值；不是OAuth access token |
| installId | 初始随机8字节hex | 用于安装身份/用量关联，可持久化 |
| version | productVersion() | 来自扩展package版本，与agent-host package.version不同 |
| serverName/productName | 固定展示名 | 用于health、协议/日志，不是认证依据 |
| tunnelProvider/publicTunnelUrl/bridgeRunning | cloudflare/null/false | 初始运行态，其他模块可修改；不是已经建立隧道 |

## 1. productVersion()

require `../../extension/package.json`，version必须匹配本项目的三段数字版本正则（可带预发布后缀），不等于完整SemVer规范认证；读取失败/无version直接抛错，不猜0.7.0。Node require存在缓存，不会自动随磁盘编辑即时热刷新。返回字符串不表示正在运行的全部发行副本已验证一致，副本一致性另由测试负责。

## 2. generateNewSecret()

先在局部变量生成新随机值，延迟require store并patch保存；只有patch正常返回才更新config.secretKey并返回新值。损坏配置或存储拒绝会向调用方抛错，内存仍保留旧凭据，不再把失败当作成功轮换。

延迟require避免顶层循环初始化；并不提供跨进程事务或fsync保证。若存储在实际发布后才报告错误，仍需核对磁盘，不自动重放；OAuth撤销在调用路由中，发生在此函数正常返回之后，不由这个函数独立完成。

## 3. persistIdentity(store)

参数是具有load/patch接口的存储对象，便于测试替换；同步执行，正常返回undefined。

先load旧值，有secretKey就取回内存，否则patch当前随机secret；再对installId同样处理。saved是初始快照，不在两次patch之间重读；store.patch自身会读最新配置，因此正常两次写能保留前一次的字段。

load/patch错误不在外层吞掉，可使入口启动失败。随后分别try调用可选protectWorkspaceSecrets和warnTrackedSecrets，错误仅在这些尽力保护步骤吞掉。不是“所有持久化错误都忽略”。

与[index入口](入口详解.md)衔接：index先验证工作区存在且为目录，再加载路由并调用persistIdentity；不会为显式不存在目录先写配置。Windows安装版默认目录创建仍由launch独立处理。

## 4. 验证与复盘

```bat
npm test --prefix webagent-core/agent-host -- --filter=hostPersist
npm test --prefix webagent-core/agent-host -- --filter=auditStorage
```

关注重启身份、坏配置与保护规则的实际断言。没有因此验证随机数所有安全性质、全部权限故障或任意端口组合。练习：区分三个时刻的secret——首次require随机值、persistIdentity恢复后的值、generateNewSecret保存失败后保留的旧值——以及它们与MCP OAuth token的不同。
