# 配置、文件、读缓存和统计的测试证据

本篇五个文件使用临时工作区，测试里出现的密钥、账号、日期均是fixture。它们不是用户账号验证，也不证明断电后的文件系统耐久性。

## stateIntegrity.test.js

[源码](stateIntegrity.test.js)异步IIFE先save默认配置，再用坏JSON覆盖磁盘。load必须E_CONFIG_CORRUPT，patch/save均拒绝且原坏字节保留。测试显式unlink模拟操作者恢复，不是产品自动删除；models错误类型拒绝后重建默认。暂换renameSync，仅目标配置路径抛磁盘错误：patch失败、原字节不变、没有.tmp.残留，finally恢复函数。

普通文件完整hash截8位不能applyPatch；已删除文件携expectedHash调用writeFile不能重建；非Windows分支atomicWriteText写工作区内符号链接，必须保留链接并更新目标。

局部**req(method,params,id)**构造IP、会话header及RPC body。创建两个HTTP session，用同名clientInfo initialize，key仍不同；没有session的key为null、board_create被拒。真实boardCreate之后未claim不能done，owner冒充被拒；A认领后B经handleRpc再认领，isError和正文ok:false均成立，tracker.fail恰加一。catch置exitCode，finally reset会话/停reporter/删tmp。未模拟跨进程同时写与Windows链接写入。

## resourceBudget.test.js

[源码](resourceBudget.test.js)先纯函数clipJson：Date转ISO不丢，带100条matches的大分页保留全部matches/nextCursor并标_budgetExceeded；巨大数组仍是数组、success真不被裁剪改义。故预算是有结构例外的软限制，不是所有JSON都硬截到固定字节。

临时root.txt含needle：readBoundedText上限3拒、readFiles传21条拒、**/*.txt匹配根文件；atomicWriteText exclusive拒EEXIST并保留needle。withWriteLock用Promise的**release**控制第一持有者；setImmediate让锁建立，第二请求在runWithSignal内排队，先abort再release，第二必须E_CANCELLED且未写bad。grep运行中abort拒绝，随后无信号grep正常，证明取消作用域不污染下次请求。创建1002空文件后listDir必须truncated且≤1000项。finally恢复workspaceRoot并删tmp；catch置exitCode。没有测百万文件耗时或实际内存峰值。

## auditStorage.test.js

[源码](auditStorage.test.js)的异步**main**先建立workspace子目录，按以下顺序验证真实存储工具：

| fixture与调用 | 必须成立 |
|---|---|
| remember/recall传穿越、非日期、2月30日等 | 校验先于建.webagent；闰日2024-02-29成功记一条 |
| memory目录挪开，原位链接到外部目录 | recall/remember拒outside，外部仍空，随后恢复目录 |
| 敏感路径大小写/嵌套/.ssh；普通.env.example | 前者敏感，普通样例允许；alias.txt→.env的resolveSafePath拒SENSITIVE |
| old分别LF/CRLF，BOM diff dryRun和实写 | dryRun不改，实写new并保持原换行 |
| malformed/两个diff/坏hash | 拒绝，不覆盖原new CRLF |
| 替换renameSync使sample目标失败 | writeFile拒、原文不变、临时文件清理，finally还原rename |
| created.txt与folder/../created.txt并发创建 | Promise.allSettled恰一成功，内容first，路径别名共享锁 |
| 非Windows的0755 run.sh | writeFile及applyPatch均保留可执行位 |
| skill为140KiB、另一项30000个中文 | 前者可列出但加载拒，后者取28000字符且truncated |
| skills链接外部目录 | listSkills不列外部项 |
| 遥测Promise待返回期间再record | release成功响应后计数仍2，不被旧快照覆盖 |

symlink文件fixture仅Windows EPERM/EACCES明确SKIP，断言在catch外，不吞失败。目录链接在Windows用junction。finally停reporter并删整个root；遥测环境变量没有原值恢复，靠单文件子进程隔离。未执行真实外网报告。

## hostPersist.test.js

[源码](hostPersist.test.js)同步**main**在tmp执行：版本等于扩展package；旧伪github/license记录迁移local-demo，而含githubId的记录保留github/octocat；generateNewSecret同步内存和磁盘；篡改内存后persistIdentity以已有磁盘值恢复。

rememberHash同时写缓存文件与session；delete require.cache重新require后recalledHash仍有而sessionHash为null，模拟模块重载而不是真的重启OS进程。断言.webagent/.gitignore保护config/read-hashes/usage、非Windows配置0600；删嵌套ignore后persistIdentity补回，非Git工作区不建根ignore。

随后真实git init，protectWorkspaceSecrets写根ignore，check-ignore应成功；force add测试配置后trackedSecretFiles找到它，warnTrackedSecrets匿名回调收一条带git rm --cached的提示；去索引后列表空，再protect不能重复行。也检查仓库顶层递归ignore规则。resetHashes清缓存/磁盘。成功路径rm tmp；无finally，失败可能遗留临时目录。所有git操作仅tmp，不触碰本项目索引；0600不等于Windows ACL验收。

## usageTracker.test.js

[源码](usageTracker.test.js)导入前设WORKSPACE_ROOT，异步**run**reset store/停定时器；record一次成功一次失败，snapshot为2/1/50%、未配置遥测，usage.json存在。patch假github身份后payload含账号ID和计数。

**fakeFetch(url,opts)**收posted并返回ok/status以及异步**text()**的空JSON；reportNow注入它，断言URL、Authorization含测试token、发送body账号与toolCalls。没有网络请求。成功路径删除遥测env、停reporter、reset store；没有rm tmp也没有finally，失败时通过process.exit结束单文件子进程。不能据此声称自动重试、服务器接收或所有错误状态已测。

## 验证

分别filter stateIntegrity/resourceBudget/auditStorage/hostPersist/usageTracker，或运行完整`npm test --prefix webagent-core/agent-host`。测试runner的子进程隔离对这些全局config/env/require缓存改动十分重要。
