# adminHost、docsSite、docsHttp：逐fixture与断言解释

这篇不是泛泛的“已有测试”：逐一解释统计完整性及文档测试文件如何构造输入、执行真实实现、断言什么，以及未证明什么。运行器把每个.test.js作为子进程执行；断言抛错/非零退出才失败，不靠控制台写PASS字样。

## 1. adminHost.test.js

[源码](adminHost.test.js)直接require admin-host/app，并使用真实HTTP server、临时目录。

**request(server,{method,url,headers,body})**：从server.address取随机端口，http.request本机；data回调收Buffer，end回调resolve status/body；req.error reject，非空body写后end。没有请求超时；依赖外层测试运行器期限。

**run()**创建os.tmpdir下mkdtemp，不触碰真实admin data。依次ingest：a/alice当日10调用1失败90%；b未绑定3调用；a/alice同日12调用92%。rankDay(loadReports)断言第一alice/12、第二空GitHub/3，证明同install/day覆盖且排序；**不证明多个install同GitHub取最新**，该路径需要另加fixture。

createServer固定测试token tok，listen(0,127.0.0.1)通过Promise回调等待就绪。try内逐请求：

| fixture | 断言 | 保护的行为 |
|---|---|---|
| POST report无Bearer | 401 | 先授权再写统计 |
| GET页面无Bearer | 401 | 本机排名也不是匿名开放 |
| GET stats无Bearer | 401 | JSON统计不得绕过页面认证 |
| GET health无Bearer | 200 | 最小健康探针公开 |
| 带Bearer新增c/carol/7 | 200 | 合法上报可受理 |
| 带Bearer读取页面 | 200且包含alice/carol/未绑定GitHub | 服务端HTML由当前数据生成，不是固定空页 |
| 带Bearer读取stats | rows[0]为alice | API排名与预期最高调用量一致 |
| Bearer有效、pad超1MiB | 413 | 正文预算拒绝，不仅检查Content-Length |
| 读取app源码 | 有crypto.timingSafeEqual、无旧直接比较文字 | **静态守卫**，不是真实时序侧信道测量 |
| 读取index源码 | 有WEBAGENT_ADMIN_BIND、无硬写listen全网 | 静态默认绑定约束，不是实际网卡测试 |
| README关键字 | 去掉“不需要令牌”旧文案，保留GET /health/Bearer | 文档防回退，不认证全文语义 |

finally server.close回调Promise，保证try中断言失败也关闭监听。F63补finally删除临时目录；run().catch打印/exit1。创建目录和listen失败仍发生在try之前，不被其finally覆盖。token文件权限未验；坏JSON400、损坏存储和写中断另由新增adminIntegrity覆盖。

## 2. docsSite.test.js

[源码](docsSite.test.js)以真实build.js进程构建，不使用手写假payload。

构建不再写当天日期，比较逐字节稳定输出，不豁免日期差异。顶层先读serve源码检查ROOT+sep边界与默认loopback（静态），检查content.js已存在；保存before，再spawnSync Node build.js，断言status0；读after直接比较before，漂移时要求重建提交。

然后vm.runInNewContext执行受控生成JS到{window:{}}，不是浏览器UI测试。断言旧summary路由实际指向review/SEMANTIC_REVIEW_2026-09-16.md、包含用户澄清的文档范围且导航有ID，不依赖过时标题字符串；退役的DOCUMENTATION_SUMMARY.md不得复活。读取manifest，for-of每个file断言其归属README在fileIndex可导航、source hash等于清单；检查至少一个正文链接指向#/source、source-index含/L；installerPackaging测试fixture源文不可嵌入可分发站点。

本轮增加两条静态回归，防止全景页再次声称arenaConnect调用本机MCP：要求包含“仅显示连接指引”，并禁止陈旧“arenaConnect 打的是本机 /mcp”。这是对已核对实现的文案防回退，不是模拟真正Arena连接。

重要副作用：build子进程会重写content.js，即使最后before/after比较失败也不会自动回滚；测试结束后应检查Git diff。未覆盖Markdown全部语法、所有危险URL协议或每个hash跳转。

## 3. docsHttp.test.js

[源码](docsHttp.test.js)与docsSite不同：启动真实serve.js子进程并发HTTP，不只读源码字符串。

**request(port,pathname)**http.get，res.resume排空body、once end resolve状态；error reject；req.setTimeout3秒destroy错误，避免单请求永久挂起。

顶层匿名async IIFE：计算仓库根，spawn serve.js，环境强制DOCS_HOST=127.0.0.1/DOCS_PORT=0，stdio管道。stderr.data累积便于报错，child.once exit兑现exited Promise。try内等待启动Promise：5秒timer超限reject；stdout.data累积文本，正则找到实际bind端口就clearTimer/resolve；child.error/exit都清timer/reject。

| 实际HTTP请求 | 断言 | 意义 |
|---|---|---|
| /%ZZ | 400 | 错误百分号编码不能让服务进程崩溃 |
| /%00 | 400 | 解码NUL明确拒绝 |
| / | 200 | 连续坏请求后服务仍能正常响应 |
| /missing-file.html | 404 | 缺资源不误报200 |

finally child.kill并await exited；最外catch打印/exitCode1。kill后等待没有额外本地kill-timeout，外层运行器仍是最后期限；测试不是检查全部目录穿越/符号链接情形，也不校验响应MIME/CSP/浏览器显示。

## 4. 验证命令与结果解释

```bat
npm test --prefix webagent-core/agent-host -- --filter=adminHost
npm test --prefix webagent-core/agent-host -- --filter=docsSite
npm test --prefix webagent-core/agent-host -- --filter=docsHttp
```

命令命中这些测试文件才有意义；三文件通过分别代表对应断言成立，不代表Admin长期运行或整个文档站已完成交互验收。Conda是用户运行环境约定，Node测试本身不要求创建venv。

docsSite移除stripBuiltAt日期豁免，要求重建逐字节相等，构建不再写当天日期。新增fixtureFs：readFileSync将全部Markdown输入转换CRLF，writeFileSync只捕获目标content.js，VM的require回调除fs外用真实模块、console.log为空；Buffer供生成器字节计数。真实build再次执行的crlfBuild必须与基线完全相等，且失败只给简短消息而不倾倒2MB差异。

新增载荷HTTP回归：docsHttp先在临时目录stage，再对源码站点与无构建工具的载荷站点各启动一次相同服务；随机端口测试首页/content.js为200、畸形路径400、缺失404，finally停止子进程并删除载荷。


## F63新增adminIntegrity.test.js

[adminIntegrity](adminIntegrity.test.js)的request(port,target,body)用真实http.request/5秒测试等待，固定假Bearer；isolatedServer(dir)启动本测试自己的--child Node，严格未处理拒绝模式、随机回环端口、10秒启动看门狗。diagnostics只用于识别ERR_INVALID_URL/退出1，不发布凭据；子进程分支只启动隔离admin。run()通过check(name,fn)收集失败，finally删除临时目录；每个子进程只kill本测试保存的ChildProcess并观察退出，不扩大PID清理。

断言：`//[`得到400，随后health仍200；原树真实子进程退出1。损坏/截断JSON、非数组、缺已知字段、4MiB超限保留原字节；受控fs.openSync模拟EACCES，以及lstat后真实删除/ENOENT不得重建空表；fs.writeFileSync/fs.renameSync注入部分临时写或发布失败，旧数据不变且无.tmp.残留。注入错误是夹具，不是真实Windows ACL或断电证据。

schema覆盖无限/小数/负计数/null、fail超过总量、错误rate、假日期、错误类型/过长文本/未知字段/null体/数组；HTTP坏JSON和1e999值为400，损坏stats在发200前失败为500/E_REPORT_STORE，health不受影响。合法同日替换和初次缺失仍工作。未证明跨进程锁、所有文件竞态、真实GitHub身份或长期容量运维。

验证：`npm test -- --filter=adminIntegrity`，再跑adminHost及完整测试；独立浏览器的adminLayoutBrowser另检真实页面，不靠字符串CSS断言代签视觉。


## adminIntegrity.test.js

来自并行分支01a0c932，随合并纳入。覆盖统计存储的**失败关闭**语义与HTTP错误形状。

辅助：**check(name,fn)**逐项执行并收集失败名；**isolatedServer(fn)**在独立子进程里起admin服务，确保一次崩溃不污染其它场景；**request(...)**发原生HTTP请求并回收状态码与响应体；**run()**串起全部场景并清理。

钉住的合同：只有**初次确实不存在**才当空账本；损坏、截断、形状不对、超预算的存储一律拒绝且**原文件字节不变**——把损坏当空会让下一条上报用一行记录覆盖掉全部历史统计；读取失败（包括stat与open之间文件消失）不得退化成空表；临时文件写入中断或rename失败时，旧数据保持原样且不留`.tmp.`残片；畸形URL与坏JSON返回400，损坏存储返回500且错误码稳定（本分支为`E_STORE_CORRUPT`，携带文件名与原因），不泄露原始EIO/EACCES；统计先算完再发200，避免头已提交后才发现错误。

合并时本分支据此补上一处：`saveReports`原先让底层写入/重命名错误直接逃逸，现在统一包成`E_STORE_CORRUPT`，HTTP层才能给出稳定形状。
