## codeServerNotRunnable.test.js

[源码](codeServerNotRunnable.test.js)全部顶层静态/文件断言，**没有真的启动一个不可运行进程**：

- 不准仓库存在bin/code-server-dist；主启动器不启动code-server，仍有agent-host路径。
- classic Shell应接受$1、检查node、默认mkdir、自定义不存在报错；VS Code Shell应检查node/拒绝缺工作区且没有mkdir。
- runtime package名称正确且无旧产品名；可选入口存在；ensure使用npm runtime/固定版本，并从extension/package.json取版本、不硬编码副本目录。
- runner依赖codeServerAuth，不硬写auth none或trusted-origins星号，不关闭workspace trust。
- 测试运行器含express依赖检查及exit2失败约定。

源码关键词匹配可能被无效注释满足，因而不能单独证明行为；与真实编排/安装测试结合阅读。

## installerPackaging.test.js

[源码](installerPackaging.test.js)在临时树执行真实collect/stage/prepareRuntime/resolveWorkspace/safeRelative/userHome，try/finally rm，未向真实Program Files安装。

1. collect(root)允许文件逐个复制到source；故意添加admin令牌、node_modules私有文件、工作区配置、冻结原型、code-server配置和manager隐私六类诱饵。
2. stage输出manifest需>50文件，含launch.js与input.cs；逐文件不能含诱饵内容，不包含冻结原型；stage到上级tmp应Invalid staging，防目的地覆盖来源。
3. prepareRuntime放home用户目录，installed真；重调路径相同；安装输出installation.json不被改；runtime用户marker重复准备仍保留；开发source不视作安装包。
4. 改payload文件后另一用户prepare必须verification failed，且releases无残留.prepare临时目录。
5. safeRelative拒../与Windows绝对路径；含空格文件路径解析成父工作区；盘符根/文件系统根允许；缺显式工作区报错且不擅自mkdir；无参数默认路径可创建；LOCALAPPDATA影响userHome。
6. 静态Inno断言AppVer、PrepareToInstall正确function签名、不使用旧ShellExec、PATH规范比较而非简单替换、仅payload通配而非整个仓库通配。

它不执行CMD/Inno界面，也不编译全部C#；真实Windows升级卸载/快捷方式/权限验证另列。
