# 工具表、文件权限与危险命令fixture

测试中危险命令仅用于拒绝分支，不应实际执行；真实命令限临时仓库git、echo和可取消Node子进程。这些规则不是完整操作系统沙箱。

## dangerousCommands.test.js

[源码](dangerousCommands.test.js)的**req(method,params)**构造直接RPC；**request(server,method,urlPath,body,headers)**本机HTTP，JSON body及长度、额外header，收data/end解析（失败null），网络error reject。**main**遍历六种rm/find删除变体（拆参数/长参数/引号混淆等）isDangerousCommand必须true；echo/npm test/git status false，push/下载管道shell/dd/shred/truncate true。

每个变体本地callTool未确认须publicError E_BAD_ARGS且提示confirm_dangerous；直接远程handleRpc即使confirm_dangerous:true也isError/E_FORBIDDEN。之后真Express装MCP/API随机端口：带secret路径MCP HTTP200但result.isError，API本地未确认≥400并有确认提示；最后安全ping仍200且非错误，防全部请求一刀切。finally关server/删tmp，main.catch exit1。未枚举所有shell等价写法，也不执行已确认危险命令。

## sandbox.test.js

[源码](sandbox.test.js)临时workspace，**trySymlink(target,dest)**只尝试创建，任何异常返回false；**main**验证默认bind（或env覆盖）、isInsideWorkspace内外区分；UNC、Windows盘符、设备前缀逐个resolveSafePath应outside workspace。

外部临时目录放LEAK文本，链接成功才验证read_files、run_command.cwd、resolveSafePath拒外部，recursive list不得出现secret.txt。Windows另测junction。**局限：junction创建和assert包在同一个宽catch里，会吞掉断言失败；普通trySymlink也对所有创建错误静默跳过。**不能凭绿灯宣称Windows链接防护完整验收。成功删两tmp，catch exit1，无finally；未模拟检查与使用之间的链接替换竞态。

## workspaceTools.test.js

[源码](workspaceTools.test.js)的**git(args)**在tmp同步调用git，非0抛stderr/stdout；**pollOutput(execId,tries=20)**最多20次查询，running每次等50ms，终态返回，否则throw。**main**按顺序串联真实工具，前一步的磁盘状态是下一步fixture。

| 组 | 输入/调用与断言 |
|---|---|
| 工具公开面 | 有git/start/delete/rename/load_skill，无lsp/diagnostics/隐藏input |
| Git | 非仓库status/diff返回available:false而不是崩；git init/config/add/commit真建临时仓库，再改keep.txt查status/diff。diff断言含正文**或**totalLines≥0，较宽松，不证明准确补丁 |
| Skills | 写demo/SKILL.md，列表和加载应有相对/绝对路径与正文；仓库bundled computer-use/project-manager存在才检查其内容 |
| 文件写删移 | delete无confirm拒，有confirm删；旧文件write无确认拒，新建/确认覆盖成功；rename目标存在；Ask删除锁住，../路径拒 |
| 敏感文件 | .env/config不可读且列表隐藏.env，.env.example可读可列 |
| 工作区信息 | root等于tmp、topLevel数组、rules与initialize.instructions提示 |
| 别名与读版本 | read_files的path获取hash，再write_file同path不显式确认可使用本轮读缓存；confirm字符串true、bash/cmd、ls/path兼容 |
| 异步执行 | echo start产生16位hex execId/running，poll终态含async-ok；长Node任务cancel，立即与250ms后均cancelled，迟到close不可写回done |
| 跨轮读缓存 | rememberHash后clearSession，sessionHash null；旧磁盘hash不得解锁write，原正文不变 |
| 子进程环境 | 注入测试OPENAI_API_KEY，再用平台对应命令查询，stdout/stderr不能出现值，随后删除env |

操作均限定tmp，但shell执行能力本身不构成OS级隔离；测试末rm，catch exit1，无finally，环境原值也非恢复而是删除。对bundled skill缺失的条件跳过、diff宽断言，应在解释证据时保留限定。
