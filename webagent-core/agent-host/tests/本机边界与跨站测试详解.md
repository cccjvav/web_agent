# 本机控制面、Origin与WebSocket握手测试

这些测试保留远程认证MCP，同时阻止远程访问本机管理API；CORS不是认证替代品。

## localControl.test.js

[源码](localControl.test.js)的**req({ip,host,headers}={})**生成ip/socket.remoteAddress与Host，默认本机；额外headers可覆盖Host。顶层同步断言：IPv4/IPv6/IPv4映射loopback真，LAN假；cf-ray/cf-connecting-ip识别隧道，无header假；Cloudflare/ngrok域名识别公网，localhost/IP本机不算公网，普通自定义域名默认不算已知隧道。

临时把config.publicTunnelUrl设自定义域名后，该Host识别公网且不属本机控制面，再恢复旧值。最后默认本机允许，cf header/Quick Host/LAN均拒。无服务监听；恢复不在finally，失败靠子进程退出隔离。

## auditControl.test.js

[源码](auditControl.test.js)的**connect(port,origin,allowed)**真ws连接/ws；3秒timer超时terminate并reject。unexpected-response清timer、resume响应，期望拒绝时核对401/403；message说明已建立，close事件后根据allowed resolve/reject，error清timer并reject。不以仅TCP连上算握手成功。

异步**main**内部箭头**req(host)**构造本机socket，untrusted/localhost.evil/逗号混Host/空/@均不能本机控制，IPv6方括号loopback允许。临时workspace、host本机、两port=0，require真实index启动UI和MCP；Promise.all等待各listening。坏Origin WS拒、本机Origin和无Origin均允许；真HTTP带恶意Host访问UI /api/status应404。finally停tracker、关闭两server、删tmp；catch exitCode1。没有真实跨站浏览器，握手由Node ws模拟；不穷举DNS rebinding与代理部署。

## corsAllow.test.js

[源码](corsAllow.test.js)先真实纯函数断言：本机Origin/扩展Origin分类，MCP允许无Origin、本机、列出的模型站和扩展，拒evil；管理API只允许无Origin/本机。暂设WEBAGENT_CORS_ORIGINS两个站扩展MCP名单，不放行evil，随后恢复原env。

**fakeRes()**含statusCode/body，**status(code)**和**json(obj)**记值并返回this供链式调用。每个匿名next回调置nextCalled：恶意API Origin或Referer不next且404；本机/无Origin next；恶意MCP不next且403，无Origin/受信站next。

**request(server,method,urlPath,body,headers)**真实本机HTTP、JSON长度、收data/end，坏JSON为null，error reject。异步IIFE临时workspace，Express装JSON、mcpCors、rejectDisallowedMcpOrigin、真实MCP router；携正确secret但恶意Origin的run_command应403且响应无EVIL_EXEC，无Origin ping应200/非工具错误。finally close/rm，catch exit1。回显未含命令不是独立磁盘副作用探针；拒绝中间件状态与负向请求一起构成证据。该文件不测浏览器预检强制机制，预检header另见HTTP冒烟。
