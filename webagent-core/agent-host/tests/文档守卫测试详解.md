# 文档策略、编辑质量与学习导航守卫

这些测试只证明有限结构契约，不是自然语言语义完整性证明；不能因全部PASS就省略人工源码复盘。

## documentationPolicy.test.js

[源码](documentationPolicy.test.js)先run真实仓库清单断言>100源文件。临时mkdtemp内git init，辅助箭头**put(p,text)**建父目录并写fixture。try/finally删除临时仓库。

| 操作 | 断言的回归风险 |
|---|---|
| 只建源码不建目录README | run抛Missing directory README，不能静默遗漏归属 |
| 补README、write再只读check | 可生成后达到稳定一致 |
| main函数改名改正文 | 无write报drift，README原字节仍等于before，检查模式不能自动改文档 |
| 新增new.js、删除main.js | 两种都导致drift，分别write修正后继续 |
| README指missing.js | write也必须Broken local link，不以生成覆盖掩盖断链 |
| source写非法function语法 | Unexpected token，AST解析不能默默退文件级成功 |
| 两个类同名same方法与箭头f(z) | 提取A/same、B/same及参数z，证明作用域区分 |
| 只有START标记 | replaceBlock抛Broken，不破坏手写正文 |

不包含所有符号类型、所有路径编码和全部非JS语言分析。依赖真实git与Acorn，但fixture仓库不推送。

## documentationQuality.test.js

[源码](documentationQuality.test.js)的docs列表含核心模块README与启动说明，逐文件取自动块之前正文；断言仅一个一级标题、有职责/流程或执行链/验证或测试，无旧手工行号列表和零散过时施工片段。逐行围栏状态机检查每个代码块声明语言、结尾闭合；表格用split('|')比较连续行列数。不是完整Markdown解析，代码中的竖线处理有已知限制。

**read(rel)**读取真实文件；语义关键词守卫要求不宣传失败自动builtin、明确MCP取消映射缺口、非四文件事务、done只是流结束、Acorn为开发依赖。

后半截从真实docs-site/app.js切出escapeText与renderFiles函数文本，vm执行；用**$**返回main、**$$**空列表、**route**返回编码中文章节、**pageChrome/go**占位。document.**getElementById**仅命中中文ID时给**scrollIntoView()**，设置scrolled。构造read & write标题，断言本页目录aria-label、&amp;转义、编码锚点及实际调用滚动。测试的是提取函数，不是完整浏览器排版；源函数边界改名会影响切片。

## documentationLearning.test.js

[源码](documentationLearning.test.js)的**read(p)**读仓库文件。config.extraSiteDocs.map建routes Map；pairs是JS→人工正文关联，artifactPairs是非JS→正文关联，不是生成讲解内容。

**namedFunctions(node,result=Set)**递归Object.values：收类声明/非computed方法、函数声明、变量绑定箭头/函数、对象属性FunctionExpression。数组forEach递归，其他对象递归；负fixture outer内cancel以及Bus constructor/broadcast必须被收集。没有收全所有语法命名方案，也不会解析HTML字符串内脚本；人工正文仍要解释匿名回调。

逐pairs：route必须有正文、正文含“验证”；按工作台module/其他script解析真实源，每个具名符号应在正文出现。**字符串出现只防明显遗漏，不证明解释正确**。逐artifactPairs：源文件非空、导航可达、正文识别basename；不声称CSS/PS/C# AST覆盖。

explainedSources合并两组，sourceManifest逐项检查所有实现与测试正文关联，不再跳过/tests/；新增测试也必须登记逐fixture说明；避免新增源文件悄悄无详解。去重docs集合逐文档再检route、围栏语言/平衡、矩形表格。

尾部Conda契约要求process.execPath/sys.executable/conda run/include-dev/NoProfile/未执行/沙箱无Conda声明；Windows检查表要求E1–E6、F/G/H、未执行、不自动删，并禁止旧33-tests数字与“不需真机”。walkthrough检查新手手册含双CMD窗口、退出码、暂缓测试/无MCP工具边界、只读核对和停止Bridge步骤；这仍只是关键词防回退，不证明步骤真机可执行。调用真实installer.package.collect确保Conda/复盘/新手手册/检查表会打包，复盘指南保留“尚须继续补齐”栏目用于未来缺口追踪。

新登记测试正文会使本测试也解析自己，故必须解释read/namedFunctions；这是自校验而非无限递归运行测试。配置/清单/构建内容须同步，否则相关测试可能先报漂移。
