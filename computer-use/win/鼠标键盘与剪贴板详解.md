# Windows输入：全部PS参数、C#方法与失败语义

覆盖[act.ps1](act.ps1)、[act-bg.ps1](act-bg.ps1)、[type.ps1](type.ps1)、[input.cs](input.cs)、[input2.cs](input2.cs)、[keys.cs](keys.cs)。**SUBMITTED只表示输入已提交，不证明应用接受、文本正确或任务完成**；不要因失败自动换输入方式重放有副作用的动作。

## 1. 两个点击脚本

act.ps1参数WindowTitle空、X/Y默认0，UTF8输出、ErrorActionPreference Stop，脚本目录Add-Type input.cs。有标题时Get-Process/Where-Object要求非零主句柄，标题用OrdinalIgnoreCase的IndexOf普通子串；必须恰好一个匹配，否则ERR_WINDOW_MISSING_OR_AMBIGUOUS/exit2。再检查p，调用WinInput.Click；ERR_*输出/exit3，其他打印CLICK+结果+坐标/标题。没标题则GetForegroundWindow再Click，允许操作当前前台，因此更要确认环境。

act-bg.ps1相同参数/唯一匹配流程，但加载input2.cs并ClickBg，成功打印BGCLICK；没有WindowTitle直接ERR_NO_WINDOW/exit2，**不默认对前台后台投递**。两脚本没有执行后截图确认，没有自动改点/双击/重试。

## 2. input.cs全部原生声明与Click

静态类**WinInput**；RECT Sequential四int字段匹配原生窗口外框。P/Invoke：**SetForegroundWindow**请求聚焦（可能被OS拒绝），**SetCursorPos**设置屏幕坐标并返回成功，**mouse_event**提交旧式鼠标事件无返回值，**GetWindowRect**读取矩形，**GetForegroundWindow**返回当前句柄。

**Click(hwnd,imgX,imgY)**：先读rect失败ERR_NORECT；请求前台，Sleep250，验证当前句柄，否则ERR_NOFOCUS；再读rect防窗口移动，验证img坐标在外框宽高内；加Left/Top转屏幕坐标，SetCursorPos失败ERR_CURSOR；Sleep80再次确认前台；mouse_event左键down(0x2)，Sleep40，再up(0x4)，返回SUBMITTED。

这是真实移动光标/抢焦点输入，不是后台控制。外框包含标题栏；最后检查之后到按键之间焦点仍可能变化；mouse_event无返回值，不能验证应用命中。没有catch/finally包鼠标释放，也没有全局输入事务锁。

## 3. input2.cs全部声明与ClickBg

静态类**WinBgInput**。RECT/POINT Sequential用于坐标；导入**GetWindowRect**、**ScreenToClient**（屏幕→客户区）、**PostMessage**异步投递、**IsWindow**、**GetCursorPos**，还有**SetForegroundWindow**声明但ClickBg并不调用。常量WM_MOUSEMOVE=0x200、LBUTTONDOWN/UP=0x201/202、MK_LBUTTON=1。

**ClickBg(hwnd,imgX,imgY)**：读before cursor失败ERR_CURSOR；IsWindow失败ERR_NOWINDOW；窗口rect失败ERR_NORECT；img坐标外框边界检查；外框原点+img得屏幕点，再ScreenToClient，失败ERR_STC；客户区x/y要求0..32767，标题栏点转负数被拒。lParam高16位y低16位x。

依次PostMessage move→Sleep60→down/MK_LBUTTON→Sleep100→up→Sleep50；任一失败ERR_POSTMESSAGE；再读cursor失败ERR_CURSOR_AFTER_SUBMISSION（此时点击可能已投递）；成功报告before/after。记录光标位置不是断言相等，也不是应用已处理消息。某应用不处理主窗口消息、需要子控件或不同权限级，会没有效果；失败前部分事件不可回滚，down成功/up失败亦须人工检查。

## 4. keys.cs全部声明与方法

静态类**WinBgKeys**；POINT保存两int。导入PostMessage/IsWindow/GetCursorPos/GetForegroundWindow/SetForegroundWindow/**keybd_event**/**GetClipboardSequenceNumber**；最后一个由type.ps1监测剪贴板外部变更。常量KEYDOWN/KEYUP/CHAR、CONTROL/V虚拟键、KEYEVENTF_KEYUP构造事件；文件头“SendInput fallback”是旧注释，实际实现用keybd_event。

**CursorText()**GetCursorPos失败返回unknown，否则x,y文本；只诊断，不作为安全条件。

**PasteClipboard(hwnd)**窗口无效ERR_NOWINDOW；保存before，先PostMessage Ctrl down，失败返回；try等待50再V down；finally无论中间成败都尝试V up及Ctrl up（&=保证两次都执行）。按下/释放任一失败ERR_POSTMESSAGE；Sleep80后返回SUBMITTED before/after。后台按键消息不等于真正全局键状态，现代应用可能忽略。

**SendChars(hwnd,text)**先IsWindow；foreach C# char按UTF16码元发WM_CHAR，每字符Sleep10；中途Post失败ERR_POSTMESSAGE_PARTIAL。代理对/复杂输入法不能视作单个统一Unicode输入动作；只针对经典控件，已发前缀不能撤回。

**PasteFg(hwnd)**检查有效；不在前台就SetForegroundWindow、Sleep400再查；仍不是则ERR_NOFOCUS且不发键。之后保存cursor，keybd_event Ctrl下/V下/V上/Ctrl上，Sleep120返回SUBMITTED。不改变光标，不等于不改变焦点；前台确认后的竞争仍存在，且没有应用级文本回读。

## 5. type.ps1参数和唯一窗口选择

WindowTitle必需，Text默认空；Method ValidateSet clip/fg默认clip；Mode ValidateSet空/char；DelayMs ValidateRange0..10000默认900；KeepClipboard开关。先UTF8/Stop、Add-Type keys.cs，按与点击脚本相同的非零句柄/大小写不敏感子串筛唯一窗口，缺/歧义exit2。

Mode=char优先：SendChars，ERR_* exit3，否则输出BGTYPE char和Text.Length，exit0，不加载/修改剪贴板；Method/DelayMs/KeepClipboard在此分支不生效。

## 6. type.ps1剪贴板分支与finally

加载Windows.Forms，new DataObject；未KeepClipboard时GetDataObject，foreach GetFormats(false)复制每种可用格式到old并标hadOld，任一快照异常ERR_CLIPBOARD_SNAPSHOT/exit3，**失败时不先覆盖剪贴板**。这不是对所有第三方延迟渲染/私有格式跨进程永不丢失的保证。

try SetText(Text)后changed=true，记GetClipboardSequenceNumber，Sleep200；Method fg走PasteFg否则PasteClipboard；ERR_*抛进catch；成功再Sleep DelayMs让应用读取，输出BGTYPE/result/chars。catch写ERR_TYPE并resultCode3。空Text可能由Clipboard.SetText拒绝；不应解释成可靠清空输入框。

finally：changed且未KeepClipboard才恢复。先比较当前sequence与写入时sequence，不同说明有外部变更，拒绝覆盖，写ERR_CLIPBOARD_RESTORE、resultCode4；相同则hadOld时SetDataObject(old,true)，否则Clear。恢复异常同exit4。**已经打印SUBMITTED后也可能以4退出**，成功信息和最终退出码都要看。KeepClipboard有意保留本次文本、也跳过旧值快照。

DelayMs不是检测应用完成，只是等待；sequence检查与恢复也不是跨进程原子锁，不能声称消除所有剪贴板竞争。外部变更时保留外部当前值优先于强制还原。

## 7. 验证与用户确认

Windows CI Add-Type编译input.cs/input2.cs/keys.cs，解析PS1，零窗口Click/SendChars必须ERR_*。它只验证部分声明/无效目标失败，**没有真实点击、输入、剪贴板多格式、焦点竞争或DPI实测**。

关联自动测试：`npm test --prefix webagent-core/agent-host -- --filter=installerPackaging`。真实操作应仅对无敏感内容的测试窗口，先截图/标记校准，再一次提交、观察实际结果；不得把“后台不移动鼠标”的目标写成适用于所有应用的强保证。本轮只写解释，不在用户桌面运行输入动作。
