# webagent.iss：每节声明与全部Pascal事件

[webagent.iss](webagent.iss)由Inno Setup 6编译成安装器，输入只接受package.js生成的output/payload；不是把源码工作区通配打包。Node准备/运行目录迁移逻辑另见[函数详解](函数详解.md)。

## 1. 预处理与Setup

#ifndef AppVer/#define默认0.6.9允许编译时外部覆盖；{#AppVer}是编译期，{app}/{autopf}等是安装运行期常量。AppId固定GUID建立升级/卸载身份，不能随意换；AppName/Publisher/Version为显示元数据。

DefaultDirName={autopf}\WebAgent与PrivilegesRequired=lowest、OverridesAllowed=dialog配合：默认用户级，可选所有用户；{autopf}会随安装模式解析，不是强制所有场景写系统Program Files。系统安装采用Program Files程序+用户可写运行数据的既定设计，数据目录实际由launch.js处理，不能仅据ISS宣称所有旧入口均满足。

ArchitecturesInstallIn64BitMode=x64compatible控制安装/注册表视图；OutputDir/output和BaseFilename决定EXE；lzma2/max+SolidCompression压缩；UninstallDisplayIcon指启动CMD，文件关联图标表现需Windows核查。ChangesEnvironment广播环境变更，**不会改已经打开的CMD进程环境**；新开终端读更新。

LicenseFile是真实ISC LICENSE，InfoBeforeFile是SECURITY.md；后者不是新增许可证。Languages条件检查编译器ChineseSimplified.isl存在才加入中文，英文总存在，编译机不具中文语言包仍可构建。

## 2. Tasks、Files、Icons与Run

Tasks四项desktopicon/appwindow/ctxmenu/addpath，均没有unchecked标志所以初始勾选；Description/GroupDescription分组显示；ctxmenu双双引号是Inno字符串内引号转义。

Files只有output/payload/*→{app}，createallsubdirs/recursesubdirs递归目录；安全性依赖package.js干净白名单，不应把“通配”误解成源码全盘收集。

Icons：桌面VS Code/app窗两项各受task控制；开始菜单提供VS Code壳、经典备用、check-env和uninstaller；工作目录{app}只是启动上下文，工作区选择仍由Node层处理。Run在安装结束可勾启动VS Code入口：postinstall/skipifsilent/shellexec/runasoriginaluser，静默安装不自动启动，使用原始用户而非延续提升权限。

## 3. Registry逐组

全部写HKCU，即使选择系统安装也只给当前用户配置这些入口，并非所有用户自动获得。

- Software\Classes\*\shell\WebAgentOpen：文件右键标题与command，command双引号包CMD路径和%1。
- Directory\shell\WebAgentOpen：目录右键，传%V；不是Directory\Background的空白处菜单。
- WebAgent.OpenWith ProgID及shell/open/command：注册为可选打开方式，不修改扩展默认双击关联。
- .md/.txt/.js/.json/.py/.html/.css下OpenWithProgids仅加WebAgent.OpenWith值。父自有key用uninsdeletekey，别人共享的扩展key只uninsdeletevalue，避免删掉其他应用关联。
- Environment/Path为expandsz，ValueData={olddata};{app}受addpath控制。保留原值后追加；卸载不用uninsdeletevalue整删Path，而交Pascal精确摘除。

若安装前同名key已有外部自定义，卸载的key删除并非自动恢复备份；不要承诺保留任意同名手工注册。运行工作区路径含引号/感叹号等仍需按launcher/Windows验收用例验证。

## 4. UninstallDelete

显式删除{app}里的agent-host/node_modules、bin/code-server-runtime、code-server-app、.cache、.local。这是旧位置运行产物清理；**没有删除用户工作区或用户外部runtime路径**。Inno另会按自己的安装日志移除安装文件，不能把此节当唯一卸载清单。若用户自己把重要文件放在明确清理的缓存目录，该规则不会自动识别为用户仓库；不要把程序目录当数据目录。

## 5. 全部Code函数/事件

| 函数/事件 | 参数/返回 | 实现和失败语义 |
|---|---|---|
| NodePresent() | 无→Boolean | 查HKLM与HKLM32 Node.js InstallPath；未发现则Exec cmd /D /C where node，等退出且ExitCode0才true。注册表命中只看存在，不检查实际版本≥18或文件完整性 |
| InitializeSetup() | 无→Boolean | 永远Result=True；无Node显示信息警告但继续安装，不自动装Node或阻止安装 |
| NormalizePathEntry(Value) | 字符串→规范文本 | trim，去包围双引号，/改反斜杠，长度>3时去尾斜杠保留盘符根；未realpath、未展开%变量% |
| StripAppFromPath() | 无→procedure | 规范{app}；HKCU Path不存在返回；repeat逐分号切Entry，CompareText规范值与app大小写不敏感比较，只剔匹配项；其他Entry保留原文，First管理分号；变化才RegWriteExpandStringValue |
| PrepareToInstall(var NeedsRestart:Boolean):String | var状态→错误文本 | Result空字符串允许继续，只有addpath被选才先StripAppFromPath去重；不设置NeedsRestart。必须是function并返回String，不是procedure |
| CurUninstallStepChanged(CurUninstallStep:TUninstallStep) | 卸载事件→无 | 仅usUninstall调用StripAppFromPath，摘当前app目录而非删除Path全值 |

PATH算法以分号为分隔，不能解析含分号目录的复杂引用；Normalize未展开环境变量，所以字面%LOCALAPPDATA%路径与展开路径未必视作相同。准备安装时先修改Path，之后若安装取消/失败不意味着该Pascal副作用自动事务回滚。RegWrite返回值未检查，不可仅凭卸载完成断言Path一定更新。

## 6. 验证

Windows CI已执行ISCC编译及installerPackaging自动检查；可通过`installer\build-installer.cmd`复现打包编译，前提Node/Inno可用。实际用户级/系统级安装、升级、卸载、右键参数、PATH幂等和数据保留仍按[Windows检查表](../review/CHECKLIST_WINDOWS.md)执行，不能把编译成功写成用户交互验收通过。
