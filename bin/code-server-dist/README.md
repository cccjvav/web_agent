# code-server-dist

嵌套路径 `lib/code-server-4.135.0/` 来自上游 **code-server 4.135.0**（MIT，https://github.com/coder/code-server）。

**不是可用的第二种运行方式。** 缺 `out/`、`node_modules`、捆绑 `lib/node`，不能启动。不要按官方 code-server README 去跑本目录。

`run-shuncode.cmd` 只运行 `shuncode-core/agent-host`。
