本地 的智能体自定义设置

          
定制智能体在项目中的工作方式。为整个团队配置工作区自定义，或创建跨项目跟随你的个人自定义。

          
          
描述你的偏好和约定，以串联智能体、技能和指令。

          

            
            
          

          

            
智能体
定义具有专属角色、工具访问权限和特定任务指令的自定义智能体。

            
技能
创建可重用的技能文件，提供特定领域知识和工作流。

            
指令
设置始终生效的指令，在整个工作区或用户配置文件中引导 AI 行为。

            
挂钩
配置由保存文件或运行任务等事件触发的自动操作。

            
MCP 服务器
连接外部工具服务器，通过自定义工具和数据源扩展 AI 功能。

MCP 服务器

          
Chat 模式才能外接 MCP。Bridge 无法调用这里配置的 MCP。

          
两边的「MCP」方向相反：这里是你去连别人的工具；Bridge 是你把自己变成 MCP。
