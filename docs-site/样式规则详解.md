# 文档站CSS：布局、选择器与渲染配合

[styles.css](styles.css)由index.html加载，消费者是app.js生成的class结构。CSS没有函数调用，需按变量、选择器组、状态与媒体查询复盘，而不是强行生成JS符号计数。

## 1. 变量与全局层

:root的bg/bg-2/bg-3分别页面/卡片/悬停底色，line边界，text/muted/faint文字层次；accent/accent-2强调，warn/danger/ok语义色，shop/kitchen/remote图层色；shadow/radius统一阴影与圆角，font/mono普通与代码字体。声明不代表每个变量都有消费者（例如danger/ok不应被解释成自动错误状态机）。

通配box-sizing:border-box将padding/border计入尺寸；html/body零margin、满高与背景；body grid固定260px导航+minmax(0,1fr)正文，height:auto/min-height:100vh让长文档自然撑高，不因固定100%高度把手机导航压成裁切行。faint提高对比度，正文中的链接常驻下划线，不只依赖与正文相近的颜色；可聚焦元素有明确outline。button继承字体，没有外部字体网络请求。

## 3. 980px媒体查询与级联

max-width980px时body单列，nav取消sticky满高、自然增高，链接/按钮inline-flex自动换行并保留至少36px高，减少竖直菜单占用但不藏搜索与导航；hero-grid/four/layout-split和layer单列，main缩padding。导航分组与文件分组的10px文字提高到12px。它没有给所有toc取消sticky，所以不能笼统说“窄屏所有固定目录都停用”。媒体查询后section-toc规则继续生效；同优先级后声明覆盖先声明，局部细节按更具体选择器胜出。

代码快照renderSource创建带source-code类的pre，显式复用代码块样式；render为代码/表格加键盘停靠点，聚焦后方向键可以滚动。没有动画开关、打印媒体规则或暗/浅切换；当前为固定深色文档站，与工作台data-theme系统分开。

## 4. 验证

`npm test --prefix webagent-core/agent-host -- --filter=docsSite`

docsSite只确认构建/快照一致，不是CSS布局测量。test:browser的docsViewerBrowser另测1440/768/390/320×全景/导读/长源码12状态的布局、导航不裁切及选定axe规则，验证卡片键盘目标与源码横滚；不是所有文档/读屏器认证。人工仍需200%缩放、更多长表格及实际桌面字体；未操作不能写作已通过。文件级讲解登记不声称CSS解析器已证明每条声明的语义。
