# 文档站CSS：布局、选择器与渲染配合

[styles.css](styles.css)由index.html加载，消费者是app.js生成的class结构。CSS没有函数调用，需按变量、选择器组、状态与媒体查询复盘，而不是强行生成JS符号计数。

## 1. 变量与全局层

:root的bg/bg-2/bg-3分别页面/卡片/悬停底色，line边界，text/muted/faint文字层次；accent/accent-2强调，warn/danger/ok语义色，shop/kitchen/remote图层色；shadow/radius统一阴影与圆角，font/mono普通与代码字体。声明不代表每个变量都有消费者（例如danger/ok不应被解释成自动错误状态机）。

通配box-sizing:border-box将padding/border计入尺寸；html/body零margin、满高与背景；body grid固定260px导航+剩余正文。a颜色/hover下划线，button继承字体。没有外部字体网络请求。

## 2. 所有组件选择器组

|---|---|---|
| .nav | sticky top0、100vh、自滚动、渐变/右边线/内距 | renderNav；不是position:fixed覆盖正文 |
| .brand/.logo/.brand h1/small | flex品牌、34px渐变图形、主副标题 | logo是CSS图形不是SVG请求 |
| .search | 满宽、输入底色边框圆角间距 | onSearch绑定input |
| .nav a.item/button.item、hover、.item.on、.sec | 菜单整行flex、选中/悬停、高层分组文字 | on由当前route选择，不参与授权 |
| .dot与.shop/.kitchen/.remote | 8px圆点与三层色 | 只是图例，不表示服务心跳 |
| .main/.topbar/h2/.kicker | min-width0防grid溢出，正文padding，标题flex与说明最大720px | pageChrome |
| .hero-grid/.card/h3/.muted/.faint | 双列1.4fr/0.9fr、卡片边框阴影、弱化文字 | 全景及其他卡片 |
| .arch/.layer及hover/remote/kitchen/shop/tag/strong/p、.port/.connector | 层级grid，110px标签+正文+端口；hover上移1px，类别底色；端口胶囊，连接说明居中 | renderMap的data-jump才提供点击，CSS本身不跳转 |

| .prose blockquote/.table-wrap/table/th/td/even行 | 引用左线，表格外层横滚、折边框、隔行底色 | 表格宽于正文也可查看 |

| .file-list/button/on/hover/.g | 文档目录纵向列表，分组标题 | renderFiles |

## 3. 980px媒体查询与级联

max-width980px时body单列，nav取消sticky满高，hero-grid/four/layout-split单列，layer也单列，main缩padding。它没有给所有toc取消sticky，所以不能笼统说“窄屏所有固定目录都停用”。媒体查询后section-toc规则继续生效；同优先级后声明覆盖先声明，局部细节按更具体选择器胜出。

代码快照renderSource创建pre而不是总在.prose容器内，不能假设所有.prose pre配色都会应用到源码页。没有动画开关、打印媒体规则或暗/浅切换；当前为固定深色文档站，与工作台data-theme系统分开。

## 4. 验证

`npm test --prefix webagent-core/agent-host -- --filter=docsSite`

该测试只确认构建/快照一致，不是CSS布局测量。人工应检查宽屏双列、980px下单列、长表格/代码滚动、目录键盘焦点和200%缩放；未操作不能写作已通过。文件级讲解登记不声称CSS解析器已证明每条声明的语义。
