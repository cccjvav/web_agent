# 文档站浏览器与静态服务：逐函数/事件讲解

覆盖[app.js](app.js)、[serve.js](serve.js)及[index.html](index.html)装配。与产品工作台的app.js不同，这里只读构建时嵌入的window.DOCS，不调用MCP来执行任务。

## 1. app.js作用域与基础函数

匿名IIFE创建私有作用域，末尾render()首次绘制。**$(sel,el=document)**首节点；**$$(sel,el=document)**节点数组。PAGES列八种页面route/label/hint；hint字段不自动等于实际搜索索引。

| 函数 | 输入/返回 | 行为与边界 |
|---|---|---|
| route() | 无→page/rest/raw | location.hash缺省#/map，去前缀再split；rest未统一decode，交具体页处理 |
| go(to) | 路由→undefined | 写hash，触发浏览器hashchange；同hash不保证重触发 |
| renderNav(active) | page→undefined | 保存旧搜索值，重建有显式label的搜索框和PAGES.map按钮，input绑定onSearch，forEach按钮click→go |
| escapeText(s) | 值→HTML安全文本 | null空，转义&尖括号双引号 |
| escapeAttr(s) | 值→字符串 | 仅替换双引号，当前搜索框双引号属性用途；不要当通用HTML转义 |
| pageChrome(title,kicker,extra='') | 片段→顶部HTML | 直接插参数，要求调用者使用可信文字/已安全片段 |

## 2. 全景与流程图

**renderMap()**用静态模板画层级、三路径、补丁流程和边界列表；初始化paintPath('a')/paintPatch。三张图层卡是原生a链接，目标从实际guide.sections标题匹配，不用旧“三条路一把扳手/临时门牌隧道”标题或不存在的guide.toc推定；可Tab/Enter激活。data-path按钮click内forEach改on后paintPath。

PATHS.a是工作台Chat→API→runChat→callTool；b是外部Agent→隧道→MCP→callTool；c是code-server/扩展→本机API。**paintPath(id)**按固定数组map step/箭头，**paintPatch()**同样map名称数组，不运行补丁，不监听实时工具进度。

全景图是静态说明，不是服务器发现结果。静态说明区分本机Chat、外部MCP与code-server扩展；arenaConnect仅显示指引。明确选择builtin才走本机探索，Plan merge配置失败停止，不再把“没Key”泛化成自动fallback。Bridge的快照轮询与WS辅助触发也分开说明。源文件沙箱也不等于任意shell命令的操作系统沙箱。

## 3. 正文与目录显示

**renderGuide()**取DOCS.guide、route.rest合并后decode；内部**compact(s)**去非字母数字/中文，便于模糊锚点匹配。sections.map出导航、四层卡片和details全文；若focus有值，find首个compact标题/ID包含者，scrollIntoView smooth并将tabIndex=-1的章节聚焦，避免键盘跳转后焦点丢在被替换的旧卡上。decode失败现在置空focus，仍渲染全文，不因坏编码阻断页面；标题来自受控仓库构建，不是任意用户HTML净化通道。

**renderProsePage(key,title,kicker)**通用impl/overview/workflow，toc.map锚点，插doc.html；route全部rest合并后decode，支持中文与标题id内的斜线；坏编码置空，无匹配不动。

**renderFiles()**从fileIndex取route ID或第一个，未知ID回首文档；Set分group，filter/map生成文档按钮，点击go(files/id)；正文显示path、toc.map章节链接、doc.html；anchor由文档ID后的全部rest合并再decode，支持含斜线的标题；异常置空，有目标才滚动。不存在的route不是HTTP404，只在客户端回退。

**renderTerms()**terms.map生成词卡；并非外部词典查询。

**onSearch()**读q trim小写；forEach导读标题、技术实现toc、fileIndex path/id、术语文本生成hits；短于2字符时移除旧search-hits；其他输入插/替结果，最多20项，无匹配时显示明确空结果提示，不残留旧结果。链接/标签经escapeText处理，文件ID按小写比较。没有全文源码/所有正文检索，不自动导航到首结果。

## 4. 源码快照与总分派

**renderSource()**decode路径失败置空，在DOCS.sources查固定key；构页面，路径/hash用textContent。无text但omitted给排除原因，没有源则提示去索引。range解析L起止，source.text.split换行forEach创建span，ID source-LN，行号补5位，textContent写源码；范围内加背景，起行存在则居中滚动。pre使用source-code类、可访问名称和tabIndex=0，长代码在自己的容器横滚，不撑宽整个页面；原始代码不因正文换行规则被硬折行。不从浏览器路径读取真实磁盘，也不eval源码。

**render()**route.page不在PAGES.some就map；renderNav后if分派上述各页面，并为.main中的pre及table-wrap设置tabIndex=0，确保窄屏下的滚动代码/表格可键盘阅读。window.hashchange→render；document.click委托closest站内#/链接，preventDefault后写location.hash。外链保留浏览器默认行为。

window.DOCS里的html是构建器生成的受控内容；部分标题/术语插值未独立转义，不可直接把服务接成不可信用户Markdown上传站。

## 5. serve.js顶层与匿名回调

启动先检查bundled.json：有标记则验证format=1、prebuilt=true及content.js存在；无标记才spawnSync当前Node运行build.js，失败exit。安装模式使用预构建快照，源码模式构建后提供服务。DOCS_PORT默认4173、DOCS_HOST默认127.0.0.1；开发预览可显式0.0.0.0，但只用于文档，不改变产品API绑定。

http.createServer回调：设Cache-Control:no-store；URL解析/路径decode/NUL检查失败400；根路径换index.html；path.join+resolve后检查ROOT或ROOT+sep前缀，越界403；fs.readFile回调错误一律404，成功按TYPES扩展MIME或octet-stream返回200/data。没有目录列表/写文件API/鉴权；路径检查是词法前缀，不是读取前realpath，别把文档根里的外部符号链接当成安全公开资源。请求方法未显式限定GET/HEAD，所有方法同一读取处理；没有读体逻辑。

server.listen回调打印实际端口（支持PORT=0测试随机端口）与绑定地址；显示本机URL不代表只监听本机，须看bind行。无显式SIGINT清理，因为主要资源是HTTP server，由进程退出释放。

## 6. index.html与content.js加载契约

HTML lang=zh-CN/UTF8/viewport，head引styles.css；aside.nav由renderNav填，main.main先显示加载提示；普通script依次content.js再app.js，保证IIFE读取DOCS前赋值已完成。没有fetch JSON，所以旧提示“浏览器会拦本地JSON”不准确，本轮改成推荐HTTP并检查两个脚本是否加载。

content.js是生成物，含window.DOCS的源码快照、HTML和路由（已移除每日构建日期），不在此手写内容；styles.css承担布局与颜色，完整CSS语义另行展开。浏览器加载失败不会自动执行npm或重建Markdown。

## 安装载荷的预构建模式
serve.js先检查bundled.json；存在则要求format=1/prebuilt=true/content.js存在，不运行build.js。不含此标记的源码checkout保持启动前重建。标记是发行模式选择，不是访问控制；服务默认仍回环、只读。安装包只带运行站点所需文件，源码与解释来自已生成的content.js快照。

非回环DOCS_HOST启动会明确警告：站点无认证且含完整源码快照，不应接公网隧道；不强行阻断显式开发预览环境的0.0.0.0绑定。

### 导航/搜索续作验证

documentationLinks额外提取实际renderGuide/renderProsePage/onSearch与escapeText，在最小DOM中验证坏编码仍能绘制、中文/斜线锚点滚动、清空/单字符移除旧结果、无匹配替换、标签转义。insertAdjacentHTML、remove、outerHTML setter记录渲染片段，getElementById/scrollIntoView记录目标；这是实际函数的VM契约验证，不冒充真实浏览器操作或所有路由覆盖。

workbench.browser中的docsViewerBrowser另用真实Chromium加载实际四份站点资源（请求白名单fixture，无外网），验证搜索切换/清空、坏guide编码、含斜线标题、三图层卡实际目标及Enter后的章节焦点；1440/768/390/320×全景/导读/长源码12个状态检查页面横溢、手机导航不被裁切与选定WCAG2/2.1 A/AA规则，长源码方向键实际横滚。默认加载开发依赖axe-core，AXE_PATH可覆盖路径。它验证真实DOM/脚本，不验证静态服务器网络、scrollIntoView动画或全部文档页面；结果须绑定对应CI，不由VM用例代签。
