# 借鉴优化说明（新手版）

## 先说结论：不是把别人的项目装进来

我们把上游项目当作设计参考，检查自己的实现，再做适合本项目的增强。没有启动上游服务或安装它的依赖，也不是整仓复制。**一些是借鉴思想，一些是我们自行补齐协议/可靠性问题，还有一些本来就存在，只做核对。**

可以把整个项目想成“一个工作台 + 一个工具管家 + 一条远程连接”：

- **工作台**：你本机看文件、聊天、批准操作的地方。
- **agent-host**：真正读写文件、运行命令、管理工具的本机程序。
- **Bridge / MCP**：让外面的 AI 按约定调用本机工具的通道；MCP像统一插座，不代表插上的工具天然可信。

## 已经落地了什么，对你有什么用

| 变化 | 用小白能理解的话说 | 哪里能看到 / 怎么判断 |
|---|---|---|
| 主机身份与能力诊断 | 先核对“连的是哪台机器、哪个工作区”，并区分能用、缺依赖、尚未验证 | Bridge里的主机诊断；对照工作区和hostInstanceId，不只看一个绿色状态 |
| 调用证据、计数与关联 | 像操作收据，把任务和实际工具调用连起来；写后可读回核对，不只听模型说“完成” | Bridge工具完成摘要及相关工具结果；统计是当前进程的有界记录，不是永久历史 |
| 内置探索的诚实说明与读文件证据 | 免费固定巡检助手会展示读到了什么、不知道什么；不是冒充大模型 | Chat选内置模型+Ask，展开Read；见专门使用指南。它不是从上游搬来的通用AI |
| Skills分层目录、正文与资源查看 | 可以找到“作业指导书”，读清楚再使用；同名说明用来源ID区分 | 技能页搜索、读正文/资源、填入Ask草稿。填入不自动发送，读脚本不等于执行脚本 |
| Skill分段读取与版本核对 | 长说明分段读；中途文件变了，不把新旧两版拼在一起 | hash绑定的续页；小型完整workflow.json可转工作流预览，仍需单独提交/批准 |
| 本机HTTP MCP与stdio接入 | 你可以明确接入本机已有的第三方工具服务；stdio是直接启动程序、通过输入输出管道交谈 | 受控执行页面：配置→预览→确认启动→发现工具。启动信任与每次工具调用批准是两道不同决定 |
| 工具目录分页、体积和超时限制 | 工具目录有多页时不漏掉后面；循环页、坏数据或一直不回应时停止 | 发现结果与错误；分页是我们自己补的协议能力，上游抽查实现并没有分页 |
| 审批队列与工作流 | 外部操作先交给你确认；多个明确步骤串起来，但不能失败后偷偷再执行一次 | 受控执行页面的等待、执行、完成、失败/未知状态；重复批准不会重复执行同一记录 |
| 工作流执行前检查 | 类似“动手前再看一眼”：你确认前文件被别人改了，可以拒绝本步并停止后续 | 可选before检查存在、内容或hash；旧工作流不会被自动加上保护，先前步骤不会自动回滚 |
| 记忆召回改进 | 不只按日期翻日记，还能按中英文关键词查，并告诉你来自哪个文件哪一行 | recall工具的query和来源结果；不是语义向量数据库，不自动跨项目找记忆 |
| 生命周期与资源预算 | 取消、超量输出、断开时停止服务，尽量不留下普通子孙进程，也不无限读输出 | 真实夹具测试、Windows Job / POSIX进程组与宿主死亡监视；这不是文件/网络沙箱 |
| Windows启动可靠性 | 修复固定PowerShell引导阶段卡住的问题；管道按字节转发，中文/引号参数保持原样 | Windows Node20/22/24各三轮stdio回归；状态只显示固定阶段/停止原因，不公开原始stderr |
| 文档入口和跨平台测试 | 不只写“支持”，还测实际浏览器操作、Windows运行和安装器构建 | CI绑定具体提交；本指南/内置探索指南现在从README和工作台帮助可以找到 |

这些变化散布在界面、agent-host、Windows辅助代码、测试、CI和文档中，所以不会表现为某一个“借鉴优化”开关。HTTP、stdio和工作流是受控执行能力，不表示内置探索器会自行决定调用它们。

## 三个实际例子

**例一：只想知道项目里有什么。** 选内置模型+Ask，要求读取README。它给文件与读取证据；需要复杂解释时再明确选择真正的模型。

**例二：让外部AI使用你装好的MCP工具。** 你先在本机审阅启动配置，确认信任程序，再发现工具。外部AI提交调用请求后，你在本机批准。发现工具不等于已允许它执行，整个流程不靠自动npx安装补依赖。

**例三：批准一串文件操作。** 给危险步骤加before条件；假如批准前别人改了文件，检查失败会停下，而不是盲目接着覆盖。它不保证文件锁和完整事务，原有expectedHash仍有意义。

## 哪些不能算“已经借鉴完成”

- 上游1,886个跟踪路径、86个分组、26类机会，是发现地图；不是逐行审完，更不是26类全实现。
- 公网第三方MCP已增加显式HTTPS/Bearer接入，真实供应商兼容性仍待验；通用网站扩展适配、独立OS沙箱、发布签名、其他尚未深入的模块，仍在队列中。
- 持久登录、多工作区隔离、后台自启等原有取舍，没有借这次改动悄悄打开。
- 已有的安装载荷hash清单、部分窗口保护等是复用/核对，不能冒充重新发明。
- CI不是你的电脑验收；你反馈完成的步骤按原范围保留，11.3协作说明已完成/关闭；具体第三方包仍需实机验证。
