# DeepSeek第三方扩展：候选接入说明（非兼容性验收）

当前项目未内置DeepSeek++，也没有完成它在当前网站、商店版本、账户和认证流程下的实机兼容性验收。旧文档中固定商店ID、必需隧道、列工具即可执行、自动注入规则等说法不再作为现行保证。

历史参考上游：https://github.com/zhu1090093659/deepseek-pp 。是否仍维护、实际安装包及权限需按选定版本核对；本项目不自动安装扩展、Native Host、记忆组件或另一个Shell执行通道。

## 如何判断能否接入

使用[第三方客户端最小核对步骤](网页ChatPlus使用指南.md)：区分扩展本机请求和云端请求，核对Streamable HTTP与认证，先workspace_info/已知文件只读调用，再检查本机Bridge真实记录。401/403不通过关闭认证来绕过。不要把网页登录、工具发现、普通对话或一条URL当作工具调用成功。

本机扩展请求是否可用localhost取决于权限和当前浏览器限制；云端请求则需要可达的认证入口。不能一概说“网页在云端，所以一定要隧道”。指令注入也不是安全边界，工作区限制和审批仍由主机负责。

启动与人工操作见[Windows新手手册](Windows新手逐步验收.md)。探针是另一套[浏览器Inspector＋主机＋Companion](../../探针入口与实际可用范围.md)，不等于DeepSeek++。
