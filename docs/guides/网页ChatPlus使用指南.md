# Chat Plus：第三方候选接入说明（非兼容性验收）

本项目没有内置Chat Plus，也没有在当前版本上认证其站点、安装包、账号或OAuth兼容性。此前文档把历史上游观察写成了“必然能用”的安装路径，现撤去这些未经当前验证的保证。

上游入口：https://github.com/aiguicai/Chat-Plus 。安装方式、商店是否存在、构建命令、站点列表和许可证均应核对你实际选定的版本，不由本说明保证。不自动克隆、安装或复制第三方源码；如要实质复用，先核对具体文件许可和分发义务，不能简单概括为“复制任何代码就传染许可证”。

## 接入前必须核对

- 是浏览器扩展发请求，还是云端服务器发请求？本机浏览器扩展具备适当权限时可能使用回环服务；云端客户端需要可达地址。不能因为聊天网站在云端就断言扩展一律必须走隧道。
- 它是否支持当前WebAgent的Streamable HTTP及实际认证流程？遇401/403核对OAuth/客户端能力，不关闭鉴权，不假设只填带密钥URL必然完成授权。
- 是否能够绑定同一会话、正确结束流式工具结果、明确拒绝不支持站点？复制URL到普通聊天正文不等于建立MCP连接。
- 第三方扩展的权限、隐私及工具执行需要单独审阅。不要为连接WebAgent额外开启不需要的Native Host或另一个Shell通道。

## 最小验证顺序

用[新手手册](Windows新手逐步验收.md)启动明确的测试工作区，核对版本和主机。确认第三方扩展实际完成认证、列工具，再只调用workspace_info和读取已知测试文件，观察真实Bridge记录。后续写操作逐次授权；不要一上来要求修项目或运行命令。失败时记录客户端版本、状态码和脱敏错误，不公开MCP密钥。

这不是本项目的Probe Companion或整合Inspector，两者不能替代彼此。当前探针能力见[入口对照](../../探针入口与实际可用范围.md)。
